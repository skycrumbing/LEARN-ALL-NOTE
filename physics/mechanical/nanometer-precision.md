## 一、先看问题：普通机械臂为什么到不了纳米级

### 数量级对照

| 设备 | 典型重复定位精度 | 能不能到纳米级 |
|------|-----------------|--------------|
| 工业六轴机械臂 | 20~100 μm | ❌ |
| 精密 SCARA / 直角坐标 | ~10 μm | ❌ |
| SMT 贴片机 | 数十 μm | ❌ |
| 固晶机 / 倒装键合机 | 亚微米 ~ 纳米 | ✅ |
| 光刻机工件台 | 1 nm 级 | ✅ |

> 微米（μm）= 10⁻⁶ m，纳米（nm）= 10⁻⁹ m。普通机械臂离纳米级还差 **3~4 个数量级**，这不是"改进一点"能到的，是机制层面的不同。

### 串联结构的误差放大

普通机械臂是**串联机构**——从基座到末端，每个关节都串着一根"误差放大链"：

```
基座 → 肩关节 → 大臂 → 肘关节 → 小臂 → 腕关节 → 末端
        ↓          ↓          ↓
   回程间隙    轴承游隙   弹性变形
```

每个环节的小误差，在末端被**力臂杠杆**放大：

- **减速器回程间隙**：几十 μm 级别，直接进入传动链
- **关节轴承游隙**：接触间隙无法消除
- **臂长的热胀冷缩**：1 m 的钢臂，温度变 1°C 就伸缩约 12 μm
- **负载弹性变形**：自重 + 负载让臂弯曲，末端下垂

末端误差是各关节误差之和（还要乘臂长杠杆），机械本身的天花板就在微米量级。

### 关键认知：芯片组装用的根本不是"手臂"

芯片组装设备（固晶机、倒装键合机、晶圆键合机）长得像**精密平台**，不像人手臂。它们把"大行程"和"高精度"拆开处理——大行程用宏动，高精度用微动，中间用闭环衔接。这就是下一节的核心思路。

## 二、核心思路：测量—反馈—补偿的闭环

### 开环 vs 闭环

```
开环:  电机 → 丝杠 → 台子
       只有"走多远"的指令，没有"走偏多少"的反馈
       → 精度取决于机械本身，微米级就到顶

闭环:  电机 → 台子 → 位置传感器（干涉仪 / 光栅尺）
                        ↓
        指令 ← 控制器算出"误差该补多少" ← 测到"现在在哪"
       → 精度取决于"测得到多细" + "补得到多准"
```

### 纳米精度的真正来源

> **精度不是"动出来的"，是"补出来的"。**
> 走一步、测一步、把误差算出来、再补掉，反复迭代到收敛。

闭环循环：

```
① 宏动:  大行程电机把台子送到目标附近（μm 级）
② 测量:  激光干涉仪 / 光栅尺读出真实位置（nm 分辨率）
③ 比较:  目标位置 − 实际位置 = 位置误差
④ 微动:  压电陶瓷把误差补掉（nm 级）
⑤ 重复 ②~④ 直到误差 < 指标
```

> **补充：精度 vs 重复定位精度。** 开环设备靠"每次走一样"来保证重复性；要得到绝对精度（指哪打哪），必须做标定+闭环。纳米级设备两者都要：重复性由低误差结构保证，绝对精度由测量闭环 + 误差补偿保证。

## 三、先测得到，才动得准：纳米级测量系统

### 激光干涉仪 —— 用光的波长当尺子

- HeNe 激光波长 λ ≈ 633 nm，本身就是一把"天然标尺"
- 两束光干涉，台子移动半个波长（~316 nm）就产生一次明暗交替
- 再对干涉条纹做**相位细分**，分辨率可到 λ/1024 ≈ **0.6 nm 以下**

```
    激光器 ──→ 分光镜 ──→ 固定反射镜
                        ↘ 测量反射镜（装在移动台子上）
      两束光干涉 → 亮暗条纹变化次数 = 移动距离 / (λ/2)
```

- 优点：分辨率纳米级、量程大、非接触
- 缺点：贵；对环境敏感——温度和气压改变空气折射率，会"污染"这把光学尺子

### 光栅尺与编码器

- 高刻线密度光栅 + 莫尔条纹细分，同样能到纳米级，而且比干涉仪便宜、对环境更鲁棒
- 宏动电机上的旋转编码器，决定宏动本身的分辨率

### 测量的硬指标

> 测量分辨率 < 目标精度一个数量级是起码要求。目标 1 nm，测量至少要能分辨 0.1 nm，否则"补"无从谈起。**测量的天花板，就是精度的天花板。**

## 四、精密平台的四大支柱

### 支柱一：低误差结构（从源头减掉误差）

| 传统结构 | 问题 | 精密结构 | 消除了什么 |
|---------|------|---------|-----------|
| 丝杠 + 齿轮 | 回程间隙 | 直线电机直驱 | 传动间隙 |
| 滚动导轨 | 摩擦、爬行 | 气浮 / 静压轴承 | 接触摩擦 |
| 铰链轴承 | 游隙、磨损 | 柔性铰链（一体切出） | 间隙、迟滞 |

- **直线电机**：磁力直驱，中间没有丝杠/减速器，就没有回程间隙
- **气浮轴承**：台子浮在气膜上，无摩擦、无磨损、无"爬行"（stick-slip）
- **柔性铰链**：一整块材料切出来的弹性结构，靠弹性变形运动，无接触、无间隙、无回程——纳米微动台的标准结构

```
柔性铰链:  ──╲  ╱──
              ╳        ← 薄壁处靠弹性弯曲，产生微小转角
            材料一体，无接触、无磨损、无回程
```

### 支柱二：微动执行器（把误差补掉）

| 执行器 | 行程 | 分辨率 | 特点 |
|--------|------|--------|------|
| 压电陶瓷（PZT） | ~100 μm | 亚纳米 | 电压→形变，闭环后几乎无迟滞 |
| 音圈电机 | ~mm | 纳米 | 响应快，适合高频微动 |
| 步进电机 | 大 | μm 级 | 只能做宏动 |

**压电陶瓷（PZT）**：给电压、材料就形变。分辨率取决于驱动电压的细分能力，亚纳米可达。它是闭环里"最后补刀"的执行器。

### 支柱三：温度控制（热膨胀是纳米级的第一敌人）

- 1 m 的钢件，温度变化 1°C → 伸长约 **12 000 nm**
- 对策：
  - **低膨胀材料**：Invar（因瓦合金，膨胀系数约钢的 1/10）、微晶玻璃（近零膨胀）
  - **主动温控**：冷却液循环把结构温度稳定到 ±0.01°C 甚至更严
  - **热补偿模型**：用温度传感器测温度场，软件把膨胀量算回来补掉——这个补偿模型背后又是矩阵（通常由有限元 FEM 解出的热变形场）

### 支柱四：振动隔离（把地面抖动挡在外）

- 地面振动、空调气流、人员走动，都是纳米级的干扰源
- **被动隔振**：气浮弹簧把系统固有频率压到 1~2 Hz 以下
- **主动隔振**：传感器测振动 + 执行器**反相抵消**——这本身就是一个实时反馈控制系统（矩阵登场的地方，见第七节）

## 五、视觉对准：机器怎么"看"到纳米

### 对准标记（mark 点）

芯片和基板上刻有十字 / 圆形对准标记，相机拍下来，和模板比对，算出"该往哪儿挪"。

### 亚像素定位：一个像素也能拆成 1/10

- 一个像素可能代表几百纳米，但通过对图像灰度做**重心法 / 曲面拟合**，特征点定位精度可到 **1/10 ~ 1/100 像素**——等效纳米级
- 配合高倍镜头，视觉给出的偏移量 (Δx, Δy, Δθ) 就是平台该补的运动量

```
模板 mark 位置  →  实际拍到的 mark 位置
        相对偏移 (Δx, Δy, Δθ)  → 平台该补的运动量
```

### 视觉与平台的衔接：坐标变换

视觉给出的是"芯片相对基板的偏移量"，要转成"平台坐标系的运动量"，中间必须经过坐标变换——**矩阵在这里正式登场**。

## 六、矩阵算法登场：精度背后的一整套线性代数

> 一句话：**位置姿态 = 矩阵，误差补偿 = 解方程，闭环控制 = 矩阵运算。**

### 1. 齐次变换矩阵（位置姿态的语言）

刚体运动 = 旋转 + 平移，用一个 4×4 矩阵表示：

```
      [ R (3×3 旋转)    t (3×1 平移) ]
  T = [                               ]
      [ 0     0     0          1     ]
```

- 芯片在什么姿态、平台该走到哪，都是矩阵
- 串联机构 = 一串矩阵相乘：T_末端 = T₁ · T₂ · ⋯ · Tₙ
- 旋转矩阵 R 是**正交矩阵**：RᵀR = I，所以 R⁻¹ = Rᵀ（求逆用转置就行，不用除法）

### 2. 误差标定（最小二乘 / 伪逆矩阵）

精密平台有系统性误差（几何误差、轴间垂直度误差、热变形），要先"测出来"再"补掉"：

- 在台面几十个点位测量误差，得到一个**超定方程组** Ax = b
- 最小二乘解：**x = (AᵀA)⁻¹Aᵀ b** —— 中间那个 `(AᵀA)⁻¹Aᵀ` 就是**伪逆矩阵（Moore–Penrose pseudoinverse）**
- 结果是误差模型，控制系统实时用它修正指令

### 3. 手眼标定：AX = XB

相机装在运动机构上，要确定"相机相对末端"的变换 X：

- 运动两次，得到两组位姿关系 A、B
- 解矩阵方程 **AX = XB**（用对偶四元数 / 李代数方法）
- 这是"眼睛"和"手"对齐的标准方程，让视觉量测能换算到机械运动

### 4. 相机标定与单应矩阵

- 相机投影模型：**x = K[R|t]X**（内参矩阵 K、外参 [R|t]）
- 平面到平面的投影是**单应矩阵 H**（3×3），解线性方程组得到
- **SVD 找最佳旋转**：经典 **Kabsch 算法**——对两组对应点构造协方差矩阵 C = UΣVᵀ，最佳旋转就是 **R = VUᵀ**。ICP 点云配准找旋转，用的也是同一招

### 5. 状态空间控制（闭环的数学形态）

- 系统状态方程：**ẋ = Ax + Bu**（A、B 是矩阵）
- **LQR 最优控制**：解代数里卡提方程 **AᵀP + PA − PBR⁻¹BᵀP + Q = 0**，得到增益矩阵 K，控制量 **u = −Kx**
- **卡尔曼滤波**：预测 + 更新两步全是矩阵运算，把干涉仪测量和系统模型融合、滤掉噪声。核心是协方差传播 **Σ′ = AΣAᵀ + Q**

### 6. 误差传播与模态分析

- 误差传播：**Σ_out = J Σ_in Jᵀ**（J 是雅可比矩阵）——下一节专门讲
- 结构振动分析 = 解**特征值问题** **Kφ = ω²Mφ**（刚度矩阵 K、质量矩阵 M），算出系统固有频率，避免共振

## 七、矩阵在六个关键场景里具体怎么干活

| 场景 | 矩阵工具 | 解决什么问题 |
|------|---------|-------------|
| 姿态与坐标变换 | 4×4 齐次变换矩阵 | 芯片 / 平台 / 相机坐标系对齐 |
| 误差标定与补偿 | 最小二乘、伪逆 (AᵀA)⁻¹Aᵀ | 把系统性误差测出来、实时补掉 |
| 手眼标定 | 矩阵方程 AX = XB | 确定相机与末端的相对变换 |
| 视觉定位 | 单应矩阵 H、SVD（Kabsch / ICP） | 把 mark 偏移换算成运动量 |
| 闭环控制 | 状态空间 A、B + LQR + 卡尔曼 | 快速、准确、无超调地到位 |
| 精度分析 | 雅可比 J + 协方差 Σ | 论证"整机到底能不能到纳米级" |
| 结构振动 | 特征值 Kφ = ω²Mφ | 避开共振，保证稳定 |

> 加粗记住：**位置姿态、误差补偿、视觉对准、闭环控制、精度分析——五件事，全都有矩阵在里面。**

## 八、误差传播：为什么精度设计要算雅可比和协方差

### 末端误差 = 各源误差通过雅可比放大

每一处微小误差（角度误差、尺度误差、热变形），通过机械结构映射到末端的位移误差，用**雅可比矩阵 J**：

```
  δp = J δq

  δq = 各关节 / 部件的微小误差
  δp = 末端位置误差
  J   = 雅可比矩阵（末端位置对误差源的偏导）
```

### 协方差传播

```
  Σ_out = J Σ_in Jᵀ

  Σ_in   = 各误差源的方差 / 协方差
  Σ_out  = 末端误差的方差
```

纳米级设计就是两件事同时做：
1. 让每个误差源的 Σ_in 足够小（低误差结构 + 温控 + 隔振）
2. 让 J 足够小（结构上不放大误差）

### 从部件精度到整机精度的设计流程

```
① 列出所有误差源（结构、热、振动、测量、控制）
② 用雅可比建立误差传播模型
③ 从目标反推每个部件该做到什么精度
④ 验证 Σ_out < 目标（通常留 3 倍裕量）
```

## 九、收束：纳米级精度的一行公式

```
纳米级精度 = 低误差结构（气浮 + 柔性铰链 + 直驱）
           × 纳米级测量（干涉仪 / 光栅尺）
           × 双级定位（宏动粗走 + 压电微动）
           × 环境抑制（温控 + 隔振）
           × 闭环控制（LQR + 卡尔曼）
           × 矩阵贯穿全程：坐标变换、误差补偿、精度传播
```

### 三个问题的最终答案

```
Q1: 为什么普通机械臂到不了纳米级?

  串联结构把每个关节的间隙、游隙、热变形逐级放大到末端
  → 微米级就是天花板，离纳米级还差 3~4 个数量级
  → 芯片组装用的不是"手臂"，是"精密平台"

Q2: 纳米级精度靠什么实现?

  核心是闭环：走一步 → 测一步（干涉仪）→ 补一步（压电）
  再配合低误差结构、温控、隔振，把误差源头减到最小

Q3: 矩阵算法扮演什么角色?

  贯穿全场：齐次变换描述姿态、最小二乘做误差标定、
  单应 / SVD 做视觉对准、状态空间 / LQR / 卡尔曼做闭环控制、
  雅可比 + 协方差做精度设计
```

## 十、知识串联

### 与数学（线性代数）

- 旋转矩阵是正交矩阵 RᵀR = I——刚体变换的核心性质，求逆即转置
- 三大矩阵分解工具在这篇文章里全部登场：**伪逆（最小二乘）、SVD（配准）、特征值（振动）**

### 与计算机（控制系统 / 导航）

- 卡尔曼滤波在 GPS、车载导航、高德导航的定位融合里是同一个东西（见 `computer/algorithms/navigation/amap-navigation.md`）
- 状态空间控制是现代控制理论的公共语言，也是自动驾驶、飞控的基础

### 与物理

- **光学干涉**：波长当尺子——物理给精度定标
- **热膨胀**：材料物理直接决定精度上限
