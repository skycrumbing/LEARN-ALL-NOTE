# 子网掩码与网段

## 前置知识：IP 地址的结构

IP 地址（IPv4）是 32 位，写成 4 个十进制数，每段 8 位：

```
192.168.1.10
↓
11000000.10101000.00000001.00001010
```

一个 IP 地址其实包含两部分：

```
IP 地址 = 网络号 + 主机号
```

- **网络号**：标识你在哪个网段（哪个"小区"）
- **主机号**：标识你在该网段中的具体设备（哪栋楼几号房）

**问题**：IP 地址本身没有告诉我们是哪几位是网络号、哪几位是主机号——这就是**子网掩码**要解决的问题。

---

## 子网掩码是什么

子网掩码（Subnet Mask）是一个 32 位的数字，用连续的 1 表示"网络号部分"，连续的 0 表示"主机号部分"。

### 最常见的子网掩码

```
255.255.255.0
↓ 二进制
11111111.11111111.11111111.00000000
↑ 前 24 位是网络号  ↑ 后 8 位是主机号
```

**规则**：子网掩码永远是连续的 1 接连续的 0，不能 1 和 0 穿插。

### 如何判断两个 IP 是否在同一网段

**方法**：把 IP 和子网掩码做"按位与（AND）"运算，得到网络号。网络号相同，就在同一网段。

#### 示例

```
IP:       192.168.1.10  →  11000000.10101000.00000001.00001010
掩码:     255.255.255.0 →  11111111.11111111.11111111.00000000
AND 结果: 192.168.1.0   →  11000000.10101000.00000001.00000000
                                 ↑ 网络号 = 192.168.1.0
```

**比较**：

| 设备 | IP | 子网掩码 | 网络号 | 同一网段？ |
|------|----|---------|--------|-----------|
| A | 192.168.1.10 | 255.255.255.0 | 192.168.1.0 | — |
| B | 192.168.1.20 | 255.255.255.0 | 192.168.1.0 | ✅ 是 |
| C | 192.168.2.10 | 255.255.255.0 | 192.168.2.0 | ❌ 否 |

A 和 B 可以直接通信，C 需要经过路由器转发。

## CIDR 表示法（斜杠记法）

子网掩码太长了，所以用 **/n** 表示前 n 位是网络号：

```
255.255.255.0  →  /24  （前 24 位是网络号）
255.255.0.0    →  /16
255.0.0.0      →  /8
```

写成 `IP/掩码` 的形式：

```
192.168.1.0/24  →  网络号 192.168.1.0，子网掩码 255.255.255.0
10.0.0.0/8     →  网络号 10.0.0.0，子网掩码 255.0.0.0
```

### 常见子网掩码速查表

| CIDR | 子网掩码 | 可用主机数 | 说明 |
|------|---------|-----------|------|
| /8 | 255.0.0.0 | 16,777,214 | A 类网络默认 |
| /16 | 255.255.0.0 | 65,534 | B 类网络默认 |
| /24 | 255.255.255.0 | 254 | C 类网络默认，最常用 |
| /25 | 255.255.255.128 | 126 | 把一个 /24 切两半 |
| /26 | 255.255.255.192 | 62 | 再切一半 |
| /27 | 255.255.255.224 | 30 | 再切 |
| /28 | 255.255.255.240 | 14 | 小网段 |
| /30 | 255.255.255.252 | 2 | 点对点链接（两个设备之间）|

> 可用主机数 = $2^{主机位数} - 2$，减 2 是因为要去掉**网络号**（全 0）和**广播地址**（全 1）。

## 广播地址和网络号

每个网段有两个特殊地址：

| 地址 | 主机位 | 用途 | 示例（192.168.1.0/24） |
|------|--------|------|----------------------|
| **网络号** | 全 0 | 标识这个网段本身 | 192.168.1.**0** |
| **广播地址** | 全 1 | 向该网段所有设备发消息 | 192.168.1.**255** |

**可用主机范围**：网络号 +1 ~ 广播地址 -1

```
192.168.1.0/24
├── 192.168.1.0     → 网络号（不可分配）
├── 192.168.1.1     → 第一个可用 IP（通常是网关/路由器）
├── 192.168.1.2 ~ 254 → 可用主机
├── 192.168.1.255   → 广播地址（不可分配）
```

## 子网划分：为什么要切分网段

### 场景：一个公司有 3 个部门

- 技术部：50 台设备
- 市场部：30 台设备
- 财务部：10 台设备

如果整个公司用一个 `/24`（254 个可用 IP），所有人都在一个网段：

- ❌ 广播包全网都能收到，影响性能
- ❌ 技术部不应该访问财务部的打印机
- ❌ 网络故障会影响整个公司

**解决方案**：划分子网，把一个大网段切成多个小网段。

### 实操：把一个 /24 切成 4 个 /26

**原始**：`192.168.1.0/24`

```
网络号：192.168.1.0
子网掩码：255.255.255.0
可用主机：254
```

**切成 4 个 /26**（子网掩码变成 255.255.255.192）：

```
子网 1: 192.168.1.0/26
  网络号：192.168.1.0
  广播：192.168.1.63
  可用：192.168.1.1 ~ 62（62 台）

子网 2: 192.168.1.64/26
  网络号：192.168.1.64
  广播：192.168.1.127
  可用：192.168.1.65 ~ 126（62 台）

子网 3: 192.168.1.128/26
  网络号：192.168.1.128
  广播：192.168.1.191
  可用：192.168.1.129 ~ 190（62 台）

子网 4: 192.168.1.192/26
  网络号：192.168.1.192
  广播：192.168.1.255
  可用：192.168.1.193 ~ 254（62 台）
```

### 二进制视角：为什么是 64 一跳

看最后 8 位的二进制：

```
/24 的边界：192.168.1.00000000
             前 26 位是网络号 ↑
             后 6 位是主机号
```

最后 8 位中，前 2 位变成了网络号的一部分：

```
00 000000  → 子网 1（0 ~ 63）
01 000000  → 子网 2（64 ~ 127）
10 000000  → 子网 3（128 ~ 191）
11 000000  → 子网 4（192 ~ 255）
```

每多 1 位子网位，网段数量翻倍，每个网段的主机数减半。

## 三大私有 IP 网段

以下 IP 段不会在公网路由，专门用于局域网：

| 网段 | CIDR | 范围 | 常见场景 |
|------|------|------|---------|
| 10.0.0.0 ~ 10.255.255.255 | /8 | 1 个 A 类网 | 大型企业内网 |
| 172.16.0.0 ~ 172.31.255.255 | /12 | 16 个 B 类网 | 中型网络 |
| 192.168.0.0 ~ 192.168.255.255 | /16 | 256 个 C 类网 | 家庭/小型办公室 |

你家的路由器默认就是 `192.168.1.0/24` 或 `192.168.0.0/24`。

---

## 一句话总结

> 子网掩码就像一把"标尺"，告诉 IP 地址哪部分是"小区名"（网络号），哪部分是"门牌号"（主机号）。两个设备网络号相同就能直接通信，不同就要靠路由器。
