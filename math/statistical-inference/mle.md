# 最大似然估计 (MLE)

> 前置阅读：`probability-distributions.md` — 抛硬币、伯努利、二项、正态、期望方差。
> 一句话定位：MLE 是"给定数据，猜让这些数据最可能出现的参数"——机器学习损失函数的源头。
> 串回：`machine-learning/neural-network-basics.md`、`cat-from-scratch.md` 里的 loss 函数根都在这里。

---

## 一、从一个硬币问题开始

### 1.1 场景

你有一枚硬币，抛 10 次，得到 7 次正面、3 次反面。问：这枚硬币正面朝上的概率 `p` 是多少？

### 1.2 直觉猜

"7 次正面占 10 次，`p` 大概是 0.7"——这是**样本频率**，也是后面 MLE 给出的答案。但我们能不能推一遍证明它就是答案？

### 1.3 用分布写下来

按 `probability-distributions.md` 里的二项分布，10 次抛硬币得到 7 正面的概率是：

```
P(X=7) = C(10,7) · p^7 · (1-p)^3 = 120 · p^7 · (1-p)^3
```

这是一个关于 p 的函数——**p 取不同值，这个概率不同**。我们要找"让 p 取什么值时，这个概率最大"。

---

## 二、似然：同一个公式，反过来读

概率和似然用的是**同一个公式**，区别只在谁是已知、谁是未知：

```
P(X | p)   概率：已知参数 p，数据 X 出现的概率是多少
L(p | X)   似然：已知数据 X，参数 p 有多"可能"

L(p | X) ≡ P(X | p)         公式一模一样
                            只是把 p 当未知量、把 X 当已知量
```

把 1.3 那个式子重新读一遍：

```
L(p) = P(7 次正面 | p) = 120 · p^7 · (1-p)^3
```

**似然函数就是"给定数据、把参数当变量"的概率函数。** 它衡量"某个 p 下，这个数据有多可能出现"。

### 2.1 直观感受

把 L(p) 画成关于 p 的曲线：

```
L(p)
 ↑
 │              ╭──╮  p ≈ 0.7 时最大
 │           ╭──╯  ╰──╮
 │        ╭──╯         ╰──╮
 │    ╭───╯                 ╰───╮
 └───┴─────┬───────┬───────┬────┴──→ p
        0.4     0.7     1.0
```

`p` 取 0.7 附近时 L(p) 最大——这就是 MLE 要找的点。

---

## 三、连乘 → 对数 → 求导

### 3.1 一般化

抛 10 次的例子简化了，实际有 n 个样本 `x_1, x_2, ..., x_n`（假设独立同分布，i.i.d.），它们同时出现的概率就是各自概率之积：

```
L(p) = ∏_{i=1}^{n} P(x_i | p)
```

### 3.2 连乘的两个麻烦

- **下溢**：很多小于 1 的小数相乘，很容易下溢成 0（计算机表示不了）
- **求导麻烦**：连乘直接求导要用莱布尼茨公式，很乱

**取对数**同时解决两者——`ln` 是单调函数，**最大值点不变**：

```
ln L(p) = ln ∏ P(x_i | p) = Σ_{i=1}^{n} ln P(x_i | p)     ← 连乘变连加
```

最大化 L(p) ⟺ 最大化 ln L(p)（因为 ln 单调递增）。

### 3.3 求导求解

标准做法：**对 p 求导 → 令其等于 0 → 解方程**。

```
p̂ = argmax_p  ln L(p)
```

## 四、伯努利 MLE 完整推导

### 4.1 写似然

设 `y_1, ..., y_n ~ Bernoulli(p)` 独立同分布，`y_i ∈ {0, 1}`：

```
L(p) = ∏ p^{y_i} · (1-p)^{1-y_i}

ln L = Σ [ y_i · ln p + (1-y_i) · ln(1-p) ]
```

（这一步用了 `P(y_i=1)=p, P(y_i=0)=1-p`）

### 4.2 对 p 求偏导

```
∂/∂p ln L = Σ [ y_i/p - (1-y_i)/(1-p) ]
```

### 4.3 令其等于 0

```
Σ [ y_i/p - (1-y_i)/(1-p) ] = 0

两边乘 p(1-p)：
Σ [ y_i·(1-p) - (1-y_i)·p ] = 0
Σ y_i - p·Σ y_i - Σ p + p·Σ y_i = 0
Σ y_i - n·p = 0

→ p̂ = (1/n) · Σ y_i                              ← 样本中正例的比例
```

### 4.4 结果

回到硬币例子：10 次抛硬币得 7 正面，`Σ y_i = 7`，`p̂ = 7/10 = 0.7`。

**这就是我们直觉猜的答案——不是巧合，是数学。**

## 五、负对数似然 → 交叉熵

机器学习习惯**最小化**损失，而 MLE 是**最大化**似然。加个负号，等价转换：

```
最大化  ln L(θ)    ⟺    最小化  -ln L(θ)
                              ↑
                    损失函数 = 负对数似然 (NLL)
```

**这就是为什么训练神经网络叫"最小化 loss"**——你最小化的那个 loss，本质就是负对数似然。梯度下降在做的"降损失"，物理含义是：**让模型下这批训练数据出现的可能性越来越大**。

把 4.1 的 ln L 拿个负号：

```
NLL = -ln L = -Σ [ y_i · ln p + (1-y_i) · ln(1-p) ]
                └──────────────────────────────────┘
                         这就是交叉熵 (Cross Entropy)
```

**分类用交叉熵，不是拍脑袋定的——是对伯努利分布做 MLE 的必然结果。**

## 六、正态 MLE 推导

### 6.1 场景

不再是硬币（离散 0/1），而是身高、误差这类**连续量**：`x_1, ..., x_n ~ N(μ, σ²)` 独立同分布。

正态分布的概率密度函数（`probability-distributions.md` 4.4 节）：

```
f(x) = 1/√(2πσ²) · exp(-(x - μ)²/(2σ²))
```

### 6.2 写似然

```
L(μ, σ²) = ∏ 1/√(2πσ²) · exp(-(x_i - μ)²/(2σ²))

ln L = -n/2 · ln(2π) - n/2 · ln σ² - (1/(2σ²)) · Σ (x_i - μ)²
```

（这里 `∏` 展开 + 取对数把指数变乘、把乘变加，是标准操作）

### 6.3 对 μ 求偏导

```
∂/∂μ ln L = (1/σ²) · Σ (x_i - μ) = 0
→ Σ x_i = n·μ
→ μ̂ = x̄ = (1/n) Σ x_i                            ← 样本均值
```

### 6.4 对 σ² 求偏导（把 σ² 当整体变量）

```
∂/∂σ² ln L = -n/(2σ²) + (1/(2σ⁴)) · Σ (x_i - μ)² = 0
→ n·σ² = Σ (x_i - μ)²
→ σ̂² = (1/n) · Σ (x_i - x̄)²                       ← 分母是 n
```

> ⚠️ 样本方差的"无偏估计"分母是 `n-1`，而 MLE 给出的是 `n`。**MLE 在小样本下有偏**——第九节再讲。

---

## 七、回归损失函数 → MSE

假设"目标值 = 模型预测 + 高斯噪声"：`y_i = μ_i(x) + ε`，`ε ~ N(0, σ²)`，则 `y_i ~ N(μ_i(x), σ²)`。

```
ln L = Σ [ -1/(2σ²)(y_i - μ_i)² ] - n/2·ln(2πσ²)

NLL = (1/(2σ²)) · Σ (y_i - μ_i)² + const
```

`const` 和 `σ²` 都是固定值，最小化 NLL ⟺ 最小化 `Σ (y_i - μ_i)²`：

```
                └────────────────────────┘
                         这就是 MSE
```

**回归用 MSE，同样是"假设高斯噪声"的必然结果。**

## 八、串回机器学习

| 你学过的 | MLE 给的统一解释 |
|---------|----------------|
| 梯度下降降损失 | 在最大似然（让数据更可能出现） |
| 分类用交叉熵 | 伯努利/多项分布下的负对数似然 |
| 回归用 MSE | 高斯分布下的负对数似然 |
| 反向传播算梯度 | 算的就是 ∂/∂θ (-NLL) |
| "过拟合" | 训练集似然逼近 1，但新数据似然崩了 |

`cat-from-scratch`、`neural-network-basics` 里的 loss 函数，根都在这里。

## 九、MLE 的局限

1. **小样本偏差**：高斯方差 σ̂² 的分母是 `n` 而非 `n-1`，小样本时系统性偏小
2. **容易过拟合**：MLE 不考虑参数先验，模型复杂时训练似然可以无限逼近 1，泛化崩盘
3. **忽视不确定性**：MLE 只给一个点估计，不告诉你"这个估计有多靠谱"

这些都催生了贝叶斯推断：**给参数加先验分布，最大化后验而不是似然**（MAP 是贝叶斯的"懒人版"）。

---

## 十、一句话总结

**MLE 是"抛硬币问题 → 似然 → 连乘→对数→求导"三步走出来的；它把"最小化 loss"统一解释成"提升数据出现的可能性"，不同 loss 函数的差别，只是对数据分布做了不同假设。**
