# 假设检验 (Hypothesis Testing)

> 一句话定位：前面学的都是"估计参数"，这一站讲"用数据做决策"。它先把"疑心"翻译成可证伪的零假设 H₀，再算一个 p 值，跟门槛 α 比，决定要不要推翻 H₀。理解 p 值的**正确读法**，你就甩开 90% 把 p 值读错的人。
> 前置阅读：`probability-distributions.md`（二项/正态/中心极限）、`mle.md`（估计）、`bayesian-inference.md`。
> 串回：全统计推断单元收官。

---

## 一、假设检验在解决什么

你手里新硬币，想知道是否公平（p=0.5）。抛 100 次得 61 正。

**61 算不算"偏到足以说明不公平"？** 公平硬币抛 100 次也可能偶然得 61 正。怎么判断"这是偶然波动，还是硬币真不公平"？

**假设检验就是：把"臆断"变成"可证伪的假设"，再用数据测它能不能站住脚。**

---

## 二、两个假设——null vs alternative

```
H₀（零假设/原假设）  "这枚硬币是公平的，p = 0.5"
H₁（备择假设）       "这枚硬币不公平，p ≠ 0.5"
```

**关键心态（无罪推定）**：愿望上想证明"不公平"（H₁），但流程	**先假设"公平"（H₀）成立**，看数据能不能在"公平"的前提下**甩出足够强的证据**推翻它。

> 被告默认无罪（H₀），除非证据强到排除合理怀疑，才判有罪（拒绝 H₀、接受 H₁）。

---

## 三、抽样分布——用上已会的二项分布

若 H₀（公平 p=0.5）为真，100 次抛硬币正面次数 X 的分布是**二项分布**：

```
X ~ Binomial(n=100, p=0.5)
```

n 够大时它接近**以 50 为中心的正态**（中心极限定理），平均 50，标准差约 √(100·0.5·0.5)=5。

观察 X=61，离中心 50 差了 11，约 **2.2 个标准差**：

```
        X 的分布 (假设 H₀ 真, 中心 50, ±约5一个σ)
       ┌─────────────────────────┐
       │      ███████████        │
       │    █████████████        │
       │   ███████████████       │
       │  █████████████████      │
  ←    └────┬─────┬─────┬────────┘  →
      观察到的 X=61 落在右边很远（离中心 11 ≈ 2.2 个标准差）
```

直觉：61 落得够远，不像公平硬币的正常波动。但要**量化**——这就是 p 值。

---

## 四、p 值——最重要也最被误解的概念

**p 值的定义（字斟句酌）**：

> **在 H₀ 成立的前提下，观察到"像现在这么极端（或更极端）"的数据的概率。**

**不是**"硬币不公平的概率"，**不是**"H₀ 是错的概率"！

例子里：

```
X ~ Binomial(100, 0.5)，H₀ 说 p=0.5
观察 X=61，双侧："极端或更极端" = X ≥ 61 或 X ≤ 39
p 值 = P(X ≥ 61 或 X ≤ 39 | H₀ 为真) ≈ 2.8%
```

**翻译成人话**：**如果硬币真是公平的，那光靠运气抛出"≥61 正"这种极端情况的概率约 2.8%。**

- p 值小 → 数据在 H₀ 下"太异常" → H₀ 越不对劲 → 拒绝 H₀
- p 值大 → 数据在 H₀ 下很常见 → 没证据推翻 H₀

### ⚠️ 最常见的误解

无数人把 "p=0.028" 读成"硬币不公平的概率是 2.8%"——**这是错的**。正确读法是**"如果硬币公平，出现这种数据的运气概率是 2.8%"**。一个断言"关于硬币"，一个是"在假设成立下的条件概率"——这是两码事。

---

## 五、显著性水平 α："p < 0.05"是谁定的

```
p < α   → 拒绝 H₀（证据够强）
p ≥ α   → 不能拒绝 H₀（证据不够，但不等于 H₀ 是对的）
```

**α 通常取 0.05**——是 Fisher 早年定的经验规矩，**不是数学定理**。0.05 意味：允许"冤枉好硬币"（误拒绝公平硬币）的概率约 5%。

> ⚠️ 注意措辞："不能拒绝 H₀" ≠ "接受 H₀"。**证据不足 ≠ 证明确实公平。** 这是被割得最多的一句话。

---

## 六、两类错误——假设检验会犯错

5% 的门槛会出错，而且是**两类不同的错**：

```
                     H₀ 是真的           H₀ 是假的
           ┌─────────────────┬─────────────────┐
  不拒绝 H₀ │   正确 ✅        │  第二类错误 ❌    │
           ├─────────────────┼─────────────────┤
  拒绝 H₀   │  第一类错误 ❌    │   正确 ✅         │
           └─────────────────┴─────────────────┘
```

```
第一类错误（Type I）＝ α ＝"把对的当错的"＝误报 / 假阳性
   → 错怪：明明公平却判不公平。概率 = α = 0.05（我们设定的）
第二类错误（Type II）＝ β ＝"把错的当对的"＝漏报 / 假阴性
   → 漏网：明明不公平却没发现。
   1 - β = 检验的"功效 / 势 (power)"
```

**两者此消彼长：α 变小（更严格）→ β 变大（更容易漏）。** "科学"不是不犯错，而是**把错误分门别类、把可控制的 α 管住**。

---

## 七、置信区间——把"估计多准"落到频率论

假设检验回答"要不要拒绝"，但没说"参数落哪、多准"。**置信区间**补这个：

> **置信区间 [L, U]**：用数据算一个区间，使得**在重复实验 95% 的情况下，这个区间会罩住真参数**。

**别读错**：不是"95% 概率真值在区间里"（真值固定，要么在要么不在）。正确理解是**"这个方法，100 次重复里有 95 次能罩住真值"**。

回到例子：抛 100 次得 61 正，p 的 95% 置信区间约 `[0.51, 0.70]`。**0.5 不在区间里** → 对应"拒绝 H₀"的结论。**检验和置信区间是同一枚硬币的两面。**

> 一句话：p 值回答"该不该拒绝"，置信区间回答"真值大概在哪、多宽"。

## 八、串回本单元 + 常见翻车点

| 你学过的 | 假设检验接上 |
|---------|------------|
| 二项/正态分布 | 抽样分布，算 p 值用的正是分布 |
| MLE 给的 σ̂、置信 | 置信区间来自"估计 ± 若干标准误" |
| 贝叶斯后验 | 频率论用置信区间、贝叶斯用"可信区间"（credible interval），后者才真的是"有 95% 概率"，前者不是 |
| 中心极限定理 | 大样本下 X 近似正态，才敢用 σ 估算 |

**5 个高频坑，记住就防住**：
1. **别把 p 值读成"H₀ 错的概率"**（它是在 H₀ 真的前提下，数据的概率）
2. **别把"不拒绝"读成"接受"**（证据不足 ≠ 证明公平）
3. **别把 0.05 当金科玉律**（人设的约定，不是天条）
4. **α 与 β 此消彼长**，单看 p<0.05 不看功效，容易漏
5. **p-hacking**：反复试验直到 p<0.05，会凭空制造大量假阳性

---

## 九、一句话总结

**假设检验 = 先假设 H₀ 成立 → 用二项/正态分布算"数据有多极端"（p 值）→ 和门槛 α 比 → 决定要不要推翻 H₀。记住 p 值是"在 H₀ 前提下数据的条件概率"、而不是"H₀ 错的概率"，你就甩开了大多数读错 p 值的人。**

## 十、自测题

1. p=0.028 的准确含义是什么？最常被误读成什么？
2. "不拒绝 H₀"和"接受 H₀"有什么区别？
3. 第一类和第二类错误是什么？为什么此消彼长？
4. 置信区间到底怎么理解？和假设检验什么关系？
5. 为什么 0.05 不是天条？

（答案：1. "若 H₀ 真，出现这么极端数据的概率约 2.8%"；误读成"硬币不公平的概率 2.8%"。2. 不拒绝 = 证据不足推翻；接受 = 断言它真，前者更严谨。3. Type I=误报公平却判不公平(α)，Type II=漏报不公平却没发现(β)；门槛严(α小)则漏得多(β大)。4. 重复实验 95% 罩住真值的区间，不是"真值在区间的概率"；0.5 不在区间 ⟺ 拒绝 H₀，两者互补。5. 是 Fisher 定的经验规矩，不是数学必然。）
