# 概率分布 (Probability Distributions)

> 一句话定位：概率分布 = "某个随机量各种取值、各有多大概率"。它是 MLE 与整个统计推断的地基——先知道分布是什么，才能谈"从数据反推参数"。
> 下一站：`mle.md` — 拿抛硬币的例子，从概率分布走到最大似然。

---

## 一、概率分布是什么

拿抛硬币来说。抛一次，要么正面（记为 1），要么反面（记为 0）。正面概率是 `p`，反面概率是 `1-p`。

把"取值 + 概率"列成一张表：

```
取值 Y | 概率
------|-----
  1   |  p
  0   | 1-p
```

**这张表就是 Y 的概率分布**——某个量各种取值、各有多大概率，列出来就完事了。

任何随机变量都能这样表示：取值是"一颗一颗数"的（离散），就列成表；取值是"连续变化"的（连续），就画成一条曲线。

---

## 二、离散 vs 连续

| 类型 | 取值方式 | 例子 | 表示 |
|------|---------|------|------|
| 离散分布 | 取值是数点：0, 1, 2, ... | 抛硬币、掷骰子、排队人数 | 表格（PMF，概率质量函数） |
| 连续分布 | 取值是连续区间 | 身高、温度、测量误差 | 曲线（PDF，概率密度函数） |

后面第三节讲离散，第四节讲连续。

---

## 三、离散分布

### 3.1 伯努利分布（抛 1 次硬币）

Y ∈ {0, 1}，P(Y=1) = p。

- **参数**：`p`（正面概率）
- **例子**：抛一次硬币、扔一次骰子得到 6、订单是否成交

### 3.2 二项分布（抛 n 次硬币，数正面次数）

抛 n 次硬币，"正面出现了几次"这个数 X 可以取 0, 1, 2, ..., n。

#### 3.2.1 公式从哪来（用 n=3, k=2 推导）

**第 1 步：假设顺序固定**

如果 3 次抛硬币的顺序被指定成"正反正"，三次是**独立事件**（一次的结果不影响另一次），所以概率相乘：

```
P(正反正) = p · (1-p) · p = p² · (1-p)
            第1次    第2次    第3次
```

关键点：**不管顺序怎么排，只要正面 2 次、反面 1 次，每种排法的概率都是 `p²·(1-p)`**——乘法可交换。

**第 2 步：数"恰好 2 次正面"有多少种排法**

3 次里挑 2 个位置放"正"（剩下自动是"反"）：

```
正反正   ✓
反正正   ✓
正反正   ✓
```

**共 3 种**，即"3 个位置里选 2 个"的组合数 `C(3,2) = 3`。

**第 3 步：把每种排法的概率加起来**

这 3 种排法互斥（不可能同时发生），所以**概率相加**：

```
P(X=2) = P(正反正) + P(反正正) + P(正反正)
       = p²(1-p)  + p²(1-p)  + p²(1-p)
       = 3 · p² · (1-p)
```

#### 3.2.2 一般化到 n, k

把 3 个具体量换回符号：

```
P(X=k) = C(n,k) · p^k · (1-p)^(n-k)
           ↑        ↑          ↑
       排法数    每排 k 次正面  每排 n-k 次反面
```

三个因子的来源：

| 因子 | 含义 | 来源 |
|------|------|------|
| `C(n,k)` | "n 次里挑 k 次正面"有多少种排法 | 组合数（数排法） |
| `p^k` | 每排里"k 次正面"的概率 | 独立事件连乘 |
| `(1-p)^(n-k)` | 每排里"(n-k) 次反面"的概率 | 独立事件连乘 |

三个因子相乘 = **"一种特定排法的概率" × "这种排法有多少种"** = 总的 P(X=k)。

#### 3.2.3 参数与例子

- **参数**：`n`（次数）、`p`（单次正面概率）
- **例子**：10 次抛硬币得到 7 正面：
  `P(X=7) = C(10,7) · p^7 · (1-p)^3 = 120 · p^7 · (1-p)^3`
  （`C(10,7) = C(10,3) = 120`——10 个位置里挑 3 个放反面）

> ⭐ 记住这个公式，MLE 全建立在它上面。

### 3.3 离散均匀分布（掷骰子）

```
取值 X | 概率
------|-----
  1   | 1/6
  2   | 1/6
  ... | 1/6
  6   | 1/6
```

每个取值概率相等。**参数**：取值范围。

### 3.4 泊松分布（单位时间事件次数，简介）

单位时间内某事件发生几次：1 分钟内到达的顾客数、1 小时内的邮件数。

```
P(X = k) = e^{-λ} · λ^k / k!
```

- **参数**：`λ`（平均发生率）
- **期望 = 方差 = `λ`**

先记住结论，后面用到再看。

## 四、连续分布

### 4.1 为什么不能直接说 P(X = x)

身高、温度、误差这类量不是"1, 2, 3"这么数，而是连续变化的。

问题来了：**"某人身高恰好等于 170.00000000 cm"的概率是多少？** 答案是 **0**。因为 170.0001、169.9999 都有可能，"恰好等于"的可能性是 0。

所以连续分布不直接说"取值 = 某数"的概率，换成**概率密度**：

```
不说 P(身高 = 170)（= 0）
而说  P(身高落在 170 ~ 171 之间)
```

### 4.2 概率密度函数（PDF）

PDF `f(x)` 本身不是概率，但满足：

```
P(X 落在 [a, b]) = ∫_a^b f(x) dx
                 ↑              ↑
              从 a 到 b    曲线下面积
```

**"曲线下的面积"就是概率。** 面积总和必须为 1（覆盖所有可能取值）。

### 4.3 均匀分布（连续）

"在 [a, b] 区间内均匀出现"——像在一段绳子上随便切一刀，切到任何位置的机会都一样。

- **参数**：`a, b`（区间端点）
- **期望**：`(a+b)/2`
- **方差**：`(b-a)² / 12`

### 4.4 正态分布（最重要的一支）

钟形曲线，两个参数：

```
μ（均值）   → 决定"钟的中心在哪"
σ（标准差） → 决定"钟多胖多瘦"

小 σ：瘦高钟（数据集中在 μ 附近）
大 σ：胖矮钟（数据分散）
```

概率密度函数（PDF）：

```
f(x) = 1/√(2πσ²) · exp(-(x-μ)²/(2σ²))
       ↑                    ↑
    归一化常数         决定钟形的部分
```

下面把形状、常数、期望方差、68-95-99.7 都推一遍。

#### 4.4.1 形状：为什么是 `exp(-(x-μ)²/(2σ²))`

想要的性质：

- **对称**：以 μ 为中心，左右完全对称
- **单峰**：在 μ 处密度最大
- **越远越小**：距离 μ 越远，密度越低，无穷远→0
- **σ 控制胖瘦**：σ 小则陡窄，σ 大则平缓

满足这四条最自然的形式：

```
exp( - (x-μ)² / (2σ²) )
```

- `(x-μ)²`：距离中心的平方，天然对称，在 μ 处为 0
- 前面加负号：`(x-μ)²` 越大，指数越小
- `exp(...)`：指数衰减，距离越远密度越低，无穷远→0
- `2σ²`：尺度因子，σ 越小分母越小，衰减越快（钟越瘦高）

#### 4.4.2 常数：为什么是 `1/√(2πσ²)`

密度函数必须满足"曲线下面积 = 1"（概率总和为 1）：

```
∫_{-∞}^{+∞} A · exp(-(x-μ)²/(2σ²)) dx = 1
```

**标准化**：令 `z = (x-μ)/σ`，则 `x = μ + σz`, `dx = σ dz`：

```
A · σ · ∫_{-∞}^{+∞} exp(-z²/2) dz = 1
```

关键就剩"高斯积分" `I = ∫_{-∞}^{+∞} exp(-z²/2) dz`。见 4.4.3。

代回去：

```
A · σ · √(2π) = 1
A = 1 / (σ · √(2π)) = 1 / √(2πσ²)
```

#### 4.4.3 高斯积分怎么算（经典极坐标技巧）

要算：

```
I = ∫_{-∞}^{+∞} exp(-x²/2) dx
```

**招数**：直接算 I 不好算，算 `I²`。

```
I² = (∫_{-∞}^{+∞} exp(-x²/2) dx) · (∫_{-∞}^{+∞} exp(-y²/2) dy)
   = ∫∫ exp(-(x²+y²)/2) dx dy              ← 两个独立积分相乘 → 二重积分
```

**换极坐标**：`x = r cosθ, y = r sinθ, x²+y² = r², dx dy = r dr dθ`：

```
I² = ∫_0^{2π} ∫_0^{∞} exp(-r²/2) · r dr dθ
```

**对 r 积分**，令 `t = r²/2`, `dt = r dr`：

```
∫_0^{∞} exp(-r²/2) · r dr = ∫_0^{∞} exp(-t) dt = 1
```

**对 θ 积分**：

```
I² = 2π · 1 = 2π
I = √(2π)                            ← 因为 I > 0，取正根
```

代回 4.4.2，得到 `A = 1/√(2πσ²)` ✓

#### 4.4.4 期望与方差怎么推

标准化 `z = (x-μ)/σ`（`x = μ + σz, dx = σ dz`），正态 PDF 变成标准正态 PDF `φ(z) = (1/√(2π))·exp(-z²/2)`。

**期望**：

```
E[X] = ∫ (μ + σz) · φ(z) dz
     = μ · ∫ φ(z) dz  + σ · ∫ z · φ(z) dz
     = μ · 1         + σ · 0
     = μ
```

- 第一项：`∫ φ(z) dz = 1`（标准正态是密度函数，面积 = 1）
- 第二项：`z · φ(z)` 是**奇函数**（关于 z=0 反对称），在 `(-∞, +∞)` 上积分为 0

**方差**：

```
Var[X] = E[(X-μ)²] = σ² · E[Z²] = σ² · ∫ z² · φ(z) dz
```

用**分部积分**算 `∫ z² · exp(-z²/2) dz`：令 `u = z`, `dv = z · exp(-z²/2) dz`，则 `du = dz`, `v = -exp(-z²/2)`：

```
∫ z² · exp(-z²/2) dz = [-z · exp(-z²/2)]_(-∞)^{+∞} + ∫ exp(-z²/2) dz
                     = 0 + √(2π)
```

（边界项在 ±∞ 处都为 0，因为 exp 衰减快过 z 增长）

代回：

```
Var[X] = σ² · √(2π) / √(2π) = σ²
```

#### 4.4.5 68-95-99.7 规则

"落在 [μ-kσ, μ+kσ] 内"的概率：

```
P(|X-μ| ≤ kσ) = ∫_{-k}^{k} φ(z) dz = 2·Φ(k) - 1
```

`Φ(k)` 是标准正态的**累积分布函数（CDF）**，无闭式解，用数值表或 Taylor 展开：

```
k = 1  →  Φ(1) ≈ 0.8413   →  P ≈ 0.6826   ≈ 68%
k = 2  →  Φ(2) ≈ 0.9772   →  P ≈ 0.9545   ≈ 95%
k = 3  →  Φ(3) ≈ 0.99865  →  P ≈ 0.9973   ≈ 99.7%
```

**记忆口诀：68-95-99.7**——工程里绝大多数场景够用。

#### 4.4.6 为什么正态最重要 + 参数与例

几乎所有"很多独立小影响叠加"的现象都近似正态——这是**中心极限定理**的推论。身高、测量误差、考试分数、噪声……都近似正态。

- **参数**：`μ, σ²`
- **期望**：`μ`
- **方差**：`σ²`
- **例**："身高 ~ N(170, 5²)"意思是"平均 170cm，68% 的人落在 165~175cm 之间"

## 五、期望与方差

知道一个分布后，最常问两件事：**平均是多少？分散有多大？**

### 5.1 期望（平均值）

本质是**按"每种取值有多可能"加权平均**：

```
离散：E[X] = Σ (取值 × 概率)
连续：E[X] = ∫ (x × 密度(x)) dx
```

用抛硬币验证：

```
Y ∈ {0,1}，P(Y=1)=p
E[Y] = 0·(1-p) + 1·p = p
       ↑             ↑
    反面的贡献    正面的贡献
```

所以"抛硬币的期望是 p"——平均下来，正面占的比例就是 p。

### 5.2 方差（分散程度）

```
方差 = E[(X - 均值)²]
     = 平均而言，取值偏离均值多远
标准差 σ = √方差
```

```
方差大 → 数据分散（胖钟）
方差小 → 数据集中（瘦钟）
```

正态分布的 `σ²` 就是方差。

### 5.3 各分布期望方差速查

| 分布 | 参数 | 期望 | 方差 |
|------|------|------|------|
| 伯努利 | p | p | p(1-p) |
| 二项 | n, p | np | np(1-p) |
| 泊松 | λ | λ | λ |
| 均匀 [a,b] | a, b | (a+b)/2 | (b-a)²/12 |
| 正态 | μ, σ² | μ | σ² |

**观察**：二项期望 `np` = 单次期望 `p` × 次数 `n`。这是**期望的线性性**，后面还会用到。

## 六、参数：分布的"旋钮"

每个分布都有 1~2 个参数，它们是"决定分布长什么样"的旋钮：

```
伯努利：p        → 一个旋钮（正面概率）
二项：  n, p     → 两个旋钮（次数 + 正面概率）
正态：  μ, σ²    → 两个旋钮（中心 + 胖瘦）
```

**给定参数 → 分布完全确定。** 反过来，MLE 就是"从数据反推这些旋钮"。

## 七、串回 MLE

现在 MLE 用到的概念都齐了：

| MLE 里出现过的 | 现在明白了 |
|--------------|----------|
| 概率分布 | 取值清单（离散）或曲线（连续） |
| 参数 | 决定分布长什么样的数（p、n、μ、σ²） |
| 似然 L(p) | "在参数 p 下，观测到的数据有多可能出现" |
| 伯努利/二项 | 抛硬币类问题 → 交叉熵损失 |
| 正态 | 身高、误差类问题 → MSE 损失 |

**MLE 做的事**：你已经有了数据（比如 10 次抛硬币得 7 正面），想知道参数 p 是多少。猜一个 p，让"这些数据最可能出现"——取对数、求导、解方程。

详细推导 → `mle.md`。

## 八、一句话总结

**概率分布 = 一个随机量的"取值—概率"清单；离散用表格，连续用曲线；每个分布由 1~2 个参数决定，MLE 就是从数据反推这些参数的方法。**
