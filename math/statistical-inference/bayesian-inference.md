# 贝叶斯推断 (Bayesian Inference)

> 一句话定位：MLE 只给一个点估计，贝叶斯给"看完数据后 θ 的一整条可能性分布"。它是 MLE 的姊妹篇，补掉 MLE"不认先验、不给置信度、小样本有偏"的三个坑。
> 前置阅读：`mle.md`（似然、连乘→对数→求导）、`probability-distributions.md`（分布、期望方差）、`loss-family-information-theory.md`（信息论收尾）。
> 串回：`mle.md`、信息论（后验越尖=熵越低=越确定）。

---

## 一、MLE 留下的疙瘩

回顾 MLE：抛 10 次得 7 正面，算出 `p̂ = 0.7`。但骨子里有几件事不对劲：

```
① 只给了 0.7 一个数——它到底有多准？抛 10 次准，抛 1000 次也准？
② 完全没考虑"你本来就知道什么"——比如这枚硬币你同事验过是公平硬币，你还硬给 0.7？
③ 小样本时 σ̂² 分母是 n 而非 n-1——MLE 在小样本下"有偏"
```

MLE 的哲学：**数据说话，参数就取"让数据最可能"的那个点。** 它天生不知道"先验"，也不告诉你"这个估计多靠谱"。

贝叶斯想补的正是这两块。

---

## 二、贝叶斯定理——读法变了

老朋友托马斯·贝叶斯给出"翻转条件概率"的公式：

```
P(θ | X) = P(X | θ) · P(θ) / P(X)
  ↑          ↑         ↑
后验      似然      先验
（看到X后   （数据   （看你原本
 对θ的看法） 怎么来）   信什么）
```

和似然放一起看，区别就出来了：

- **MLE 只关心 `P(X|θ)`**，在参数空间里找最大化它的 θ
- **贝叶斯关心 `P(θ|X)`**，把先验 `P(θ)` 也拉进来，得到"看完数据后对 θ 的一整条分布"

一句话：**MLE 问"哪个 θ 让数据最可能"，贝叶斯问"看了数据后，θ 的各种取值各还有多大概率为真"。**

---

## 三、猜硬币，从先验到后验

回到抛硬币 `p`。贝叶斯**不把 p 当常数，而当成一个有分布的量**。你心里对 p 原本有个信念——**先验**，记为 `P(p)`。

用最友好的**均匀先验**：你觉得 p 可能取任何值，先验处处相等（连续上用 `贝塔(1,1)`）。

然后抛 10 次得 7 正面，用贝叶斯公式逐点更新：

```
P(p | 7正面) ∝ P(7正面 | p) · P(p)      （∝ 意思是"正比于"，相机不管分母 P(X)）
             = [C(10,7)·p⁷(1-p)³] · P(p)
```

- 没抛之前：对每个 p 信念一样多（均匀先验）
- 抛完 10 次：`p=0.7` 附近 `P(7正面|p)` 最大 → **后验在 p≈0.7 处鼓起一座峰**

**这就是贝叶斯学习的本质**：先验（旧信念） → 数据更新 → 后验（新信念）。

- 数据→后验峰
- 峰越尖 = 你越确定 p
- 抛 1000 次得 700 正面，峰比抛 10 次得 7 正面**尖得多**——你更确定 p 接近 0.7

这补上 MLE 的 ①：**贝叶斯给的不是一个数，而是一整条"p 的可能性分布"，峰的宽窄就是置信度。**

## 四、那个"看不懂的分母" P(X)——归一化

贝叶斯公式里那个 `P(X)` 是哪儿来的？为了让后验真的是个概率分布（所有 θ 的后验加起来 = 1）：

```
P(θ | X) = P(X|θ) · P(θ) / P(X)
                              └ 归一化常数 = ∫ 所有 θ 的 P(X|θ)P(θ) dθ
```

**名字叫"边缘似然"（证据）**。它不依赖 θ，只是保证概率加起来 = 1。很多时候算不出来（那个积分），练手时常用 `∝`（正比于）跳过——第 3 节就是这么做的。

**代价**：参数多、先验复杂时这个积分算不动 → 引出后面的 MCMC 采样等"近似贝叶斯"。

---

## 五、共轭先验——让计算变简单的取巧

那个积分通常很难。但**如果先验的"形状"和似然匹配**，后验会和先验同一种类型，积分有闭式解——这组配对就叫**共轭先验**。

抛硬币是最经典的例子：

```
先验：p ~ 贝塔(α, β)         （均匀先验就是 贝塔(1,1)）
似然：抛了 a 次正面、b 次反面   （伯努利/二项）
后验：p ~ 贝塔(α+a, β+b)      ← 还是贝塔！参数机械加一下
```

**大白话**：贝塔先验 + 伯努利似然 = 贝塔后验，参数 `(α, β)` 加上 `(正面数, 反面数)` 就完事。

- 均匀先验 `贝塔(1,1)` 抛 7 正 3 反 → `贝塔(8, 4)`，**均值** `8/12 ≈ 0.667`，峰(众数) `7/10 = 0.70`
- 抛 700 正 300 反 → `贝塔(701, 301)`，**均值** `701/1002 ≈ 0.700`，峰(众数) `700/1000 = 0.70`，但**尖得多**

先验 `(1,1)` 相当于"假装预先抛过 1 正 1 反"，所以后验均值分别是"8/12"（= 8 正 4 反）和"701/1002"。**看均值**：抛 10 次时 `0.667` 被先验拉离 `0.7`，抛 1000 次时 `0.700` 几乎回到 `0.7`——**先验影响被数据稀释，数据越多越逼近 MLE**。而峰（众数）在均匀先验下恰好恒等于 MLE `a/(a+b)`（详见 5.1）。

> 均匀先验 `(1,1)` 相当于"假装预先抛过 1 正 1 反"——先验是往数据里加的平滑剂。

### 5.1 完整手算：贝塔(8,4) 的后验长什么样

上面只说"参数机械加一下"，这里把后验的完整表达式推一遍，看看数学细节。

**贝塔分布**（参数 α, β）三条性质先备好：

```
f(p) = C · p^(α-1) · (1-p)^(β-1)      （C 是归一化常数）
均值  E[p] = α/(α+β)
众数  mode  = (α-1)/(α+β-2)           (α>1, β>1)
```

**三步算出后验**：

```
① 先验（均匀）＝ 贝塔(1,1)，密度 ∝ p⁰(1-p)⁰ = 常数
② 似然（抛 7 正 3 反）＝ C(10,7)·p⁷(1-p)³ ∝ p⁷(1-p)³   （常数 C 可并入归一化）
③ 后验 ∝ 先验 × 似然 ＝ 常数 × p⁷(1-p)³
   ── 这正好是 贝塔(1+7, 1+3) = 贝塔(8,4)：
```

验证：贝塔(α,β) 密度里指数是 `p^(α-1)`。α=8 给 `p⁷`——真是"先验的 1"和"数据的 7"加在一起形成指数 7 = (α-1)。

代入 α=8, β=4：

```
均值 = α/(α+β) = 8/(8+4) = 8/12 ≈ 0.667
众数 = (α-1)/(α+β-2) = (8-1)/(8+4-2) = 7/10 = 0.70
```

**四个数放一起对照**：

| 量 | 值 | 怎么来的 |
|----|-----|---------|
| MLE `p̂` | 7/10 = 0.70 | 只看数据 |
| 后验众数 | 7/10 = 0.70 | 均匀先验下 = MLE（因为 MAP=MLE） |
| 后验均值 | 8/12 ≈ 0.667 | 被先验"假装 1 正 1 反"拉低 |
| 后验方差 | 8·4/((8+4)²·13) ≈ 0.017 | 越小 = 后验越尖 = 越确定 |

**重点**：均匀先验下众数恰好 = MLE（先验平坦，不影响 argmax）。所以"先验会影响结果"要**用均值看**，不是说峰位变了——这恰好和"贝叶斯逼近 MLE"的主体结论一致。而方差 0.017 就是让你知道"这个 0.7 有多可信"。

## 六、MAP——贝叶斯的"懒人版"，接回 MLE

你可能听过 MAP（最大后验估计）：

```
MLE:  θ̂ = argmax  P(X|θ)            只最大化似然
MAP:  θ̂ = argmax  P(X|θ)·P(θ)        最大化"似然×先验"
```

**MAP = 在"数据说的"和"你本来信的"之间找折中的最优解。**
- 先验均匀（P(θ)=常数）时，MAP 退化成 MLE
- 先验有偏向（觉得硬币公平）时，MAP 会把估计往先验拉一点——这就是**正则化的雏形**

串起来：**MLE ⊂ MAP ⊂ 贝叶斯**
- MLE = MAP 当先验均匀的特例
- MAP = 贝叶斯"只取后验峰值、丢掉整条分布"的懒人版

## 七、串回：贝叶斯补掉 MLE 的三个坑

| MLE 的坑 | 贝叶斯怎么补 |
|---------|-----------|
| ① 只给一个点，多准不知道 | 给一整条后验分布，峰尖=置信度 |
| ② 不认先验 | 显式纳入 P(θ)，数据再多也留痕（但会被稀释） |
| ③ 小样本有偏 | 加了先验的锚定，小样本更稳 |

**信息论的呼应**：后验越尖 = 熵越低 = 越确定。贝叶斯更新就是在**缩小对 θ 的不确定性**——和压缩 / 熵是同一件事。

> 贝叶斯"先验会被数据淹没"这一点，和 MLE 的行为恰好衔接：数据无限多时，贝叶斯估计逼近 MLE。两者不是对立的，是一个光谱的两端。

---

## 八、一句话总结

**贝叶斯推断 = 把"先验 × 似然"用贝叶斯定理转成"后验"。MLE 问"哪个 θ 让数据最可能"，贝叶斯问"看了数据后 θ 有多大概率为真"；后验峰尖=置信度，先验会被数据稀释，共轭先验让计算有闭式解，MAP 是只取峰值的懒人版。**

## 九、自测题

1. `MLE` 和 `MAP` 在什么时候完全一样？
2. 均匀先验 `贝塔(1,1)` 加抛 7 正 3 反，后验是什么？峰在哪？
3. 为什么贝叶斯"抛 1000 次"比"抛 10 次"的估计更尖？
4. 那个归一化常数 P(X) 为什么可以暂时用 ∝ 跳过？

（答案：1. 当先验是均匀分布（P(θ) 为常数）时，MAP 退化成 MLE。2. 贝塔(1+7, 1+3)=贝塔(8,6)，峰在 8/14≈0.57（先验"假装抛过 1 正 1 反"拉低了 0.7）。3. 因为后验 = 先验×似然，数据越多，似然越尖，越承认 p≈0.7。4. 因为它不依赖 θ，只是归一化常数，取极值/趋势时被"正比于"吸收。）
