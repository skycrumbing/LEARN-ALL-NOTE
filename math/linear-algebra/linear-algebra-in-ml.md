## 线程 A：拟合 = 最小二乘 = 投影

几乎所有"拟合"都是同一个问题：方程比未知数多、且带噪声，$b\notin\operatorname{col}(A)$，于是退到"找离 $b$ 最近的点"：

$$
\min_x\|Ax-b\|^2\ \Rightarrow\ A^\top A\hat x=A^\top b\ \Rightarrow\ \hat x=A^+b
$$

线性回归、多项式拟合、神经网络最后一层，全都是它换了件衣服；$A^\top A$ 病态或奇异时，换上 SVD 伪逆 $A^+=V\Sigma^+U^\top$（② + ⑤）。

## 线程 B：方差/信息 = 协方差矩阵的特征值

协方差矩阵 $\Sigma=\mathbb E[(x-\mu)(x-\mu)^\top]$ 是对称半正定矩阵，套用④⑦：**特征值 = 各方向方差、特征向量 = 主方向**。最大的特征值方向就是"数据铺得最开"的第一主成分 → PCA 的数学来源，SVD 一步实现（⑤）。

误差怎么从输入传到输出？用③的 Jacobian（非线性变换的局部线性化）：

$$
\Sigma_{out}=J\,\Sigma_{in}\,J^\top
$$

这正是你在 `physics/mechanical/nanometer-precision-math.md` 里写过的 $\Sigma_{out}=J\Sigma J^\top$。

## 线程 C：换基 = 酉变换 = 信号处理

卷积是循环矩阵（④），被 DFT 对角化 → 特征值 = 频率响应；DFT 矩阵又是酉矩阵（⑥）→ 保长度 → Parseval 能量守恒。①②④⑥四篇合起来，就是你 `fft-digital-signal.md` 和 `convolution-theorem.md` 的完整骨架。

## 三线合体：卡尔曼滤波

卡尔曼滤波 = **B 的协方差传播 + A 的最小二乘**，交替递归：

- **预测**：协方差随状态线性变换传播 $P^-=FPF^\top+Q$——就是 $\Sigma_{out}=J\Sigma_{in}J^\top$，其中 $J=F$；
- **更新**：把"先验（均值 $\hat x^-$、协方差 $P^-$）"和"观测（$z$、协方差 $R$）"按**逆协方差加权**融合——本质是带权最小二乘，权重就是各家的不确定性。

所以卡尔曼滤波不是黑盒子：**它 = 协方差矩阵的线性传播 + 逆协方差加权的投影**。你在纳米精度笔记里已经用过它，现在是它背后的两行线性代数。

## 决策速查表（遇到问题 → 用什么）

| 你遇到的问题 | 线性代数工具 |
|---|---|
| 方程比未知数多、带噪声 | 最小二乘 / 伪逆 |
| 降维、找主方向 | 协方差特征值 / SVD |
| 图像 / 数据压缩 | 截断 SVD |
| 去噪 / 滤波 / 均衡 | 卷积对角化 / DFT |
| 多步递推、稳态（PageRank） | 对角化 $A^k$ |
| 刚体对齐 / 坐标回算 | 正交/旋转矩阵、SVD |
| 误差从输入传到输出 | Jacobian $\Sigma_{out}=J\Sigma J^\top$ |

## 结束语

一条主线串全章：**矩阵 = 线性变换**。秩（多少维信息）、行列式（缩放多少）、特征值（不变方向缩放多少）、SVD（旋转-缩放-旋转）、正交（保不保长度）——每一个"要背的公式"都变成了"这个变换在干什么"的一个侧面。
