# 向量、矩阵与线性变换：从"数表"到"变换"

> 全章的第一块地基。核心就一句话：**矩阵不是数表，是一种"变换"（一个函数）**。摁住这句话，后面行列式、逆、特征值、SVD 全部变成"这个变换在干什么"，而不是要背的公式。

## 一、向量：不止是"一堆数字"

一个向量有**三种等价看法**：

- **物理**：一个箭头（有方向、有长度）
- **计算机**：一个有序数组 `[1, 2, 3, 4]`
- **数学**：一个满足"加法 + 数乘"这两个运算的抽象对象（这正是后面矩阵变换要作用的东西）

DFT 里那根 4 点信号：

$$
x=[1,\ 2,\ 3,\ 4]
$$

就是一个 4 维向量。图像呢？一张 28×28 的灰度图，拉平就是 $28\times28=784$ 维的向量；彩色图每个像素三通道，再乘 3。**所以"信号""图像""特征"，数学上统统是向量。**

## 二、矩阵 = 线性变换（全章的根）

矩阵 $A$ 不是一堆数字摆在那儿，它是一台**机器**：喂进去一个向量 $x$，吐出来一个新向量 $y$：

$$x\ \xrightarrow{\ A\ }\ y=Ax$$

它满足两条规矩，叫**线性**：

$$
A(u+v)=Au+Av,\qquad A(c\,u)=c\,Au
$$

（先加再变 = 先变再加；先乘常数再变 = 先变再乘常数。）

### 关键性质：矩阵的「列」就是基向量变换后的去向

标准基向量 $e_1=[1,0]^\top$、$e_2=[0,1]^\top$ 一进 $A$：

$$
Ae_1=\text{第 1 列},\qquad Ae_2=\text{第 2 列}
$$

所以**只要知道两个基向量去哪了，$A$ 作用在任何向量上的结果就完全定了**。这就是"矩阵=变换"的几何含义：$A$ 是对整个空间做一次拉伸 / 旋转 / 剪切。

几个 2D 例子（numpy 可验）：

| 名字 | 矩阵 | 在干什么 |
|------|------|----------|
| 单位 | $\begin{bmatrix}1&0\\0&1\end{bmatrix}$ | 什么也不做 |
| 缩放 | $\begin{bmatrix}s_x&0\\0&s_y\end{bmatrix}$ | x 轴拉 $s_x$ 倍、y 轴拉 $s_y$ 倍 |
| 旋转 $\theta$ | $\begin{bmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{bmatrix}$ | 逆时针转 $\theta$ |
| 剪切 | $\begin{bmatrix}1&k\\0&1\end{bmatrix}$ | x 方向"推斜"，点越高推得越远 |

```python
import numpy as np
A_scale = np.array([[2, 0], [0, 3]])   # 缩放：x 拉 2 倍，y 拉 3 倍
A_rot   = np.array([[0, -1], [1, 0]])  # 旋转 90°
A_shear = np.array([[1, 1], [0, 1]])   # 剪切
x = np.array([1, 1])
A_scale @ x, A_rot @ x, A_shear @ x    # → [2,3]  [-1,1]  [2,1]
```

## 三、矩阵乘法 = 复合变换

$AB$ 的意思是：**先做 $B$，再做 $A$**（从右往左读）。因为

$$
(AB)x = A(Bx)
$$

所以矩阵乘法的本质是把两个变换**串起来**，得到一个"一步到位"的新变换。

注意**一般不可交换**：

$$
AB \neq BA
$$

几何上很好懂：先旋转再剪切 ≠ 先剪切再旋转，顺序不同结果就不同。

这就是你在纳米精度笔记里写过的**齐次变换** $T = T_\text{rot}\,T_\text{trans}$：右乘的那个（平移）先发生。**矩阵乘法的顺序对应操作顺序，别写反。**

## 四、换基：这样看 DFT 才通透

一个向量的数字，取决于你**用什么基**。同一个箭头，在不同坐标系下坐标不同；换基这件事，就是一个（可逆）矩阵。

**直接照进你已经写好的 FFT 笔记**：

$$
X = \mathbf W_N\,x
$$

- 矩阵 $\mathbf W_N$ 的第 $k$ 行是第 $k$ 个频率的"探测波"；$X[k]$ 就是 $x$ 跟它做的**内积（投影）**：

$$
X[k] = \sum_{n}x[n]\,e^{-j2\pi kn/N} = \langle x,\ \mathbf w_k\rangle
$$

- 换个说法：$x$ 是信号在**时间基**下的坐标，$X$ 是同一个信号在**频率基**下的坐标，$\mathbf W_N$ 就是把时间基换成频率基的**基变换矩阵**。
- 而且 $\mathbf W_N$ 是**酉矩阵**（$\mathbf W_N\mathbf W_N^\*=NI$），意思是"换基保长度"——这正好是你 FFT 笔记里 Parseval 能量守恒（时域能量 = 频域能量）的线性代数来源：**换基不改变向量的长度**。

一句话：**DFT 不是什么神秘公式，就是"换个基看看"；FFT 只是把这个换基算得更快。**

## 五、小结与速查

| 概念 | 一句话 | 应用钩子 |
|------|--------|----------|
| 向量 | 箭头 / 数组 / 抽象对象 | 信号、图像、特征 |
| 矩阵 | 一种线性变换 | 缩放 / 旋转 / 剪切、齐次变换 |
| 矩阵乘法 | 复合变换（从右往左） | 先平移后旋转 = 右乘平移 |
| 换基 | 换个坐标系读同一个东西 | DFT、图像旋转 |
