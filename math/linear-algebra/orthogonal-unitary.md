# 正交矩阵与酉矩阵：保长度、保角度的变换

> 收口篇：前面反复出现的"$Q$ 正交""$W_N W_N^\*=NI$""旋转不改变长度"，这一篇把它们统一成一个概念——**正交矩阵（实数）/ 酉矩阵（复数）= 不改变长度和角度的变换**。

## 一、正交矩阵：长度、角度都不变

定义：实方阵 $Q$ 满足 $Q^\top Q = QQ^\top=I$，即

$$
\boxed{\ Q^{-1}=Q^\top\ }
$$

等价说法：$Q$ 的列是**两两正交、单位长**（标准正交基）。

核心性质，一行证明：

$$
\|Qx\|^2=(Qx)^\top(Qx)=x^\top Q^\top Q x=x^\top x=\|x\|^2
$$

**长度不变**。角度也不变：内积 $(Qu)^\top(Qv)=u^\top Q^\top Qv=u^\top v$，所以 $u,v$ 的夹角 $=Qu,Qv$ 的夹角。

具备这个性质的变换只有两类：**旋转**（$\det=+1$）和**镜像**（$\det=-1$）。

| 例子 | 矩阵 | 类型 |
|------|------|------|
| 旋转 $\theta$ | $\begin{bmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{bmatrix}$ | $\det=1$ 旋转 |
| 镜像 | $\begin{bmatrix}-1&0\\0&1\end{bmatrix}$ | $\det=-1$ 翻转 |
| 换行换列 | 置换矩阵 | 坐标轴对调 |

## 二、酉矩阵 = 复数版的正交矩阵

复数世界里，向量长度是 $\|z\|^2 = z^*z$（$^*$ = 共轭转置 = 转置再取共轭）。把"转置"换成"共轭转置"，正交矩阵就升级成**酉矩阵**：

$$
\boxed{\ U^*U = UU^*=I,\qquad U^{-1}=U^*\ }
$$

性质照旧：保复长度 $\|Uz\|=\|z\|$、保内积。（实数是复数的特例：实数时 $U^*=U^\top$，酉矩阵退回正交矩阵。）

## 三、应用 1：DFT 矩阵是酉矩阵 → Parseval 能量守恒

这是本篇最漂亮的收口——你 `fft-digital-signal.md` 里的 Parseval，本质就是"DFT 换基保长度"。

DFT 矩阵 $W_N$ 的元素 $W_N[k,n]=e^{-j2\pi kn/N}$。它和共轭转置相乘：

$$
(W_N W_N^*)[k,l]=\sum_n e^{-j2\pi kn/N}e^{+j2\pi nl/N}=\sum_n e^{j2\pi(l-k)n/N}=N\,\delta_{kl}
$$

所以 $W_N W_N^*=NI$，即**归一化后 $\frac1{\sqrt N}W_N$ 是酉矩阵**。

于是对 $X=W_N x$：

$$
\|X\|^2=X^*X=x^*W_N^*W_Nx=N\,x^*x=N\|x\|^2
\ \Rightarrow\ \frac1N\sum_k|X[k]|^2=\sum_n|x[n]|^2
$$

**这正是 Parseval 能量守恒**——"时域能量 = 频域能量"，一句话说清：**DFT 是酉变换（换基），酉变换保长度，所以能量不丢。**

numpy 复核 $W_4 W_4^*=4I$：

```python
import numpy as np
N = 4
W = np.exp(-2j*np.pi/N * np.outer(np.arange(N), np.arange(N)))
W @ W.conj().T    # → 4*I，对角全 4，其余 0
```

## 四、应用 2：旋转矩阵（几何 / 机器人 / Kabsch）

旋转矩阵是正交矩阵里 $\det=+1$ 的那一支：保长度、保角度、保方向。你在 `physics/mechanical/nanometer-precision-math.md` 里 Kabsch 求得的最优旋转 $R=VU^\top$（SVD 出）就是正交矩阵——把点云**刚体旋转**过去，不拉伸、不畸变。齐次变换里的旋转子块 $R$ 也是这类。

## 五、应用 3：为什么工程上偏爱正交矩阵（数值角度）

1. **求逆免费**：$Q^{-1}=Q^\top$，转置就行。
2. **不放大误差**：正交阵的所有奇异值都 $=1$（条件数 $=1$），代入含噪声的数据不会把噪声放大——对比病态矩阵（奇异值悬殊）会爆炸。
3. **坐标好算**：正交基下，任意向量的坐标 = 它和基的内积（投影），不用解方程。

这三点解释了你前面见到的：**DFT 数值上稳定（酉）**、**QR 分解 / SVD 用正交矩阵做数值求解**、**PCA 用正交主方向**。

## 六、小结与速查

| 概念 | 一句话 | 应用钩子 |
|------|--------|----------|
| 正交矩阵 | $Q^\top Q=I$，保长度保角度 | 旋转、镜像 |
| 酉矩阵 | 复数版，$U^*U=I$ | DFT 矩阵 |
| $\|Qx\|=\|x\|$ | 保长度（一行证） | — |
| $\det Q=\pm1$ | $+1$ 旋转 / $-1$ 镜像 | Kabsch $R=VU^\top$ |
| DFT 酉性 | $W_N W_N^*=NI$ | Parseval 能量守恒 |
