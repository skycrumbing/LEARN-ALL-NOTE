# 行列式与逆矩阵：体积缩放与"撤销"变换

> 前两篇说了「矩阵=变换」「秩=信息维数」。这一篇把两个绕不开的标量/矩阵补上：**行列式（determinant）告诉你变换把空间"放大/翻转"了多少，逆矩阵（inverse）把变换"撤销"掉。** 两者都长在同一个根上——$A$ 有没有"压扁"空间。

## 一、行列式 = 体积缩放因子（几何本质）

用单位方块做探针：把它送进 $A$，出来的是个平行四边形，**它的面积就是 $|\det A|$**。三维同理是单位立方体的体积，变成平行六面体。

几个一眼看穿的例子（$\det\ $ 就是"面积/体积被放大了几倍"）：

| 矩阵 | 在干什么 | $\det$ | 读法 |
|------|----------|--------|------|
| $\begin{bmatrix}2&0\\0&3\end{bmatrix}$ | 缩放 | $6$ | 面积 ×6 |
| 旋转 $\theta$ | 旋转 | $1$ | **旋转不改变面积**（$\cos^2+\sin^2=1$） |
| $\begin{bmatrix}1&k\\0&1\end{bmatrix}$ | 剪切 | $1$ | 平行四边形同底同高，面积不变 |
| $\begin{bmatrix}-1&0\\0&1\end{bmatrix}$ | 镜像 | $-1$ | 面积不变、**朝向翻转** |

所以行列式带符号：**$|\det A|$ 是体积缩放倍数，符号表示有没有翻转朝向（镜像）。**

2×2 和 3×3 的算法：

$$
\det\begin{bmatrix}a&b\\c&d\end{bmatrix}=ad-bc,
\qquad\text{3×3 用展开式（第一行）×代数余子式}
$$

### 最关键的两条性质

$$
\boxed{\ \det(AB)=\det(A)\det(B)\ }
\qquad
\boxed{\ \det(A^{-1})=\dfrac{1}{\det(A)}\ }
$$

第一条就是"复合变换，缩放因子相乘"；第二条说明求逆把缩放**倒过来**。

## 二、$\det = 0$ ⟺ 把空间"压扁" ⟺ 不可逆

回忆第二篇那个列相关的矩阵 $\begin{bmatrix}1&2\\3&6\end{bmatrix}$：

$$
\det = 1\cdot6 - 2\cdot3 = 0
$$

它把整个平面拍扁成一条线——**面积被压成 0，所以行列式是 0**。这不是巧合，是一堆说法的等价链条：

$$
\boxed{\ \det A = 0 \iff \operatorname{rank}<n \iff \text{零空间非零} \iff A\text{ 不可逆}\ }
$$

面积/体积被压成零 ⟺ 丢了一维信息（秩不满）⟺ 有非零向量被拍成 0 ⟺ **没有逆**（信息丢了就救不回）。行列式、秩、零空间、可逆性，四个词讲的是**同一件事**。

## 三、逆矩阵 = 撤销变换

$A$ 做了个变换，$A^{-1}$ 把它**原样还原**：

$$
A^{-1}A = AA^{-1} = I
$$

（先做 $A$ 再做 $A^{-1}$ = 什么也没做。）它只在"没压扁任何维度"时存在，也就是**方阵 + 满秩 + $\det\ne0$**。

2×2 直接给你公式（分母就是 $\det$，一眼看出"$\det=0$ 就没有逆"）：

$$
A=\begin{bmatrix}a&b\\c&d\end{bmatrix}
\ \Rightarrow\ 
A^{-1}=\frac{1}{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}
$$

手算一个：$A=\begin{bmatrix}1&2\\3&4\end{bmatrix}$，$\det=4-6=-2$，

$$
A^{-1}=\frac{1}{-2}\begin{bmatrix}4&-2\\-3&1\end{bmatrix}
=\begin{bmatrix}-2&1\\\tfrac32&-\tfrac12\end{bmatrix}
$$

```python
import numpy as np
A = np.array([[1,2],[3,4]])
np.linalg.det(A)            # → -2.0
np.linalg.inv(A)            # → [[-2,  1], [ 1.5, -0.5]]  与手算一致
A @ np.linalg.inv(A)        # → 单位矩阵，确实"撤销"了
```

## 四、应用 1：坐标回算（相机 / 机械臂）

你在齐次变换里写的 $T = T_\text{rot}T_\text{trans}$，把**A 坐标系**里的点映射到**B 坐标系**：

$$
p_B = T\,p_A
$$

工程上经常要反着来——已知 $p_B$，问它原来在 A 系里是哪。**乘逆矩阵**：

$$
p_A = T^{-1}\,p_B
$$

相机外参、机械臂正逆解、手眼标定（你纳米精度笔记里的 $AX=XB$）全是这套"正向变换 + 求逆回算"。而"能不能回算"，本质就是问 $\det T\ne0$（没被压扁、信息没丢）。

## 五、应用 2：解方程 $Ax=b$ 时，为什么不直接求逆

数学上，方阵满秩时确实能写 $x=A^{-1}b$。但**数值计算里几乎不真算 $A^{-1}$**，两个原因：

1. **慢**——求逆比"解方程"（高斯消元/分解）运算量更大；
2. **不稳**——当 $\det A$ 接近 0（病态，各列几乎共线）时，$A^{-1}$ 的元素会爆到巨大，一点噪声放大得离谱。

工程标准做法是**不显式求逆**，改用矩阵分解求解：可逆方阵用 $LU$ 分解，超定用 $QR$（或正规方程），最通用的是**下一步要讲的 SVD**——它连 $\det=0$ 的病态/非方阵都能给出"最稳妥的伪逆"。

> 一句话：**行列式告诉你"这个变换健不健康"，逆矩阵是"撤销"动作，但真要解方程，动手求逆往往是下策。**

## 六、应用 3（前瞻)：Jacobian 行列式 = 局部缩放

前面都是线性变换。**非线性变换在局部看仍是线性的**——函数 $f$ 在某点的导数矩阵（叫 **Jacobian** $J$），就是那一点的线性近似。于是：

$$
|\det J| = \text{该点附近的局部面积/体积缩放倍数}
$$

你有两处已经在用它：

- **误差传播**（纳米精度笔记里的 $\Sigma_{out}=J\Sigma J^\top$）：$J$ 正是一阶线性近似，把输入协方差"搬运"到输出，其背后的"局部缩放"思想就是 $\det J$。
- **概率变量代换 / 归一化流（Normalizing Flows）**：从 $x$ 换到 $y=f(x)$ 的概率密度要乘以 $|\det J|^{-1}$，否则面积变了概率没补偿。这是生成模型里一个活跃的技巧。

（这一块不用现在吃透，先知道"行列式 = 缩放因子"这个直觉在非线性、概率里照用不误即可；`概率统计` 那章会再回来。）

## 七、小结与速查

| 概念 | 一句话 | 应用钩子 |
|------|--------|----------|
| $\det A$ | 体积缩放倍数（绝对值）+ 朝向（符号） | 判断变换健不健康 |
| $\det=0$ | 空间被压扁、信息丢失、不可逆 | 与秩/零空间等价 |
| $\det(AB)$、$\det(A^{-1})$ | 缩放相乘 / 缩放取倒数 | 复合与撤销 |
| $A^{-1}$ | 撤销变换 | 坐标回算、解方程 |
| $J$ / $\det J$ | 局部线性化 / 局部缩放 | 误差传播、概率代换 |
