# 条件熵与互信息 (Conditional Entropy & Mutual Information)

> 一句话定位：熵只衡量"一个变量自身的不确定性"，没回答"里有多少是新的"。互信息就是 `H(X)−H(X|Y)`——知道 Y 让 X 少掉多少不确定性，等价于 KL 散度。决策树选特征、特征选择都在用它。
> 前置阅读：`information-theory.md`（熵、交叉熵、KL 散度）。
> 串回：决策树 ID3、特征选择、MLE/KL。

---

## 一、上一站留的钩子

上一站结束时有个表：最小化交叉熵 ⟺ 最小化 **KL(p‖q)**。那里 KL 的两个分布是"标签 vs 模型"。但 KL 还能干一件更基础的事——**度量两个变量之间有没有关系**。这就是互信息。

## 二、单看熵不够

回到掷骰子，两个骰子：

- **骰子 A**：均匀骰子，1~6 各 1/6，熵 `H(A) = log₂6 ≈ 2.58`
- **骰子 B**：灌铅骰子，80% 出 6，熵 `H(B) ≈ 1.19`

问：**哪个更难猜下一次点数？** 显然是 A（信息更分散）。

但换个场景——**天气预报**。假设某地明天 90% 下雨，熵 `H(天气) = 0.469`（很小）。可你真的"知道天气"了吗？不一定——"下雨"丢了太多细节：下多大？下多久？几点下？

所以**熵小 ≠ 信息全**。熵只衡量"一个变量本身的不确定性"，它没回答 **"这个变量里到底有多少是新的、别处拿不到的"**。

---

## 三、条件熵——知道 Y 后，X 还剩多少不确定性

### 3.1 想法

信息论解决"信息重合"的思路：**如果我已经知道了 Y，那 X 还剩多少不确定性？**

这就是**条件熵 `H(X | Y)`**——"给定 Y 之后，X 的条件熵"。它回答"抛开 Y 已经告诉我的，X 里还有多少是新的"。

直觉先判定：

```
你已经看到"天上有乌云"(Y) → "今天下雨"(X) 的不确定性大减
→ H(天气 | 是否有乌云) 远小于 H(天气)
Y 和 X 完全无关（Y=彩票号码） → 知道 Y 对猜 X 毫无帮助，H(X|Y) = H(X)
```

### 3.2 定义

```
H(X | Y) = Σ p(y) · H(X | Y=y)        ← "给定每个 Y 取值"的熵，再按 Y 的分布加权平均
         = Σ_y Σ_x p(x,y) · (-log₂ p(x|y))     ← 展开写成联合分布和条件概率
```

核心就一句：**H(X|Y) = 当你已经知道 Y 的每个取值时，X 剩余不确定性的加权平均。**

---

## 四、互信息——知道 Y 让 X 少了多少不确定性

把两个数放一起：

```
I(X; Y) = H(X) − H(X | Y)
          ↑         ↑
       X本身的    知道Y后X的
      不确定性    剩余不确定性
```

**互信息就是"知道 Y 帮我省掉了多少不确定"——也就是 Y 对 X 提供的信息量。**

三个边界用直觉验证：

```
Y 完全决定 X（Y 就是 X 的备份）
  → H(X|Y) = 0，I(X;Y) = H(X)     ← Y 包含 X 的全部信息
Y 与 X 完全无关
  → H(X|Y) = H(X)，I(X;Y) = 0     ← Y 不提供任何 X 的信息
Y 只提供一部分
  → 0 < I(X;Y) < H(X)             ← 中间情况
```

**互信息的两个关键词：非负、对称。**
- `I(X;Y) ≥ 0`，只有完全独立时才等于 0
- `I(X;Y) = I(Y;X)`——X 对 Y 有多少信息，Y 对 X 就有多少

> 注意到：互信息非负、等于 0 当且仅当独立——特征和上一站 KL 散度一模一样。第 5 节会揭示它们是同一回事。

---

## 五、掷骰子把三个公式算一遍

**带噪声骰子**：真实点数 X 均匀（1~6），但读数 Y 是"X + 小噪声"（读数偶尔 +1）。

```
H(X) = log₂6 ≈ 2.58                 ← X 本身的不确定性
H(X|Y) = 很小（Y≈X，知道 Y 几乎就知道 X）  ← 比如 ≈ 0.5
I(X;Y) = H(X) − H(X|Y) = 2.58 − 0.5 ≈ 2.08   ← 一个读数带来约 2 比特信息
```

对比**完全无关**（Y = 彩票号码）：

```
H(X|Y) = H(X) = 2.58
I(X;Y) = 2.58 − 2.58 = 0            ← 彩票号码对点数没贡献
```

**互信息大的变量能预测另一个，互信息为 0 的变量纯粹是噪声。**

---

## 六、金钥匙：互信息 = KL 散度

现在揭晓它和 KL 是同一回事：

```
I(X; Y) = KL( P(x, y) ‖ P(x)·P(y) )
                  ↑          ↑
             联合分布     如果X、Y独立会是啥样
```

互信息 = **KL 散度，衡量"真实的联合分布"跟"假装 X、Y 完全独立时的联合分布"差多远。**

这个视角很漂亮：

- X、Y 独立 → 真实联合 `P(x,y)` = `P(x)P(y)` → 与独立假说 KL = 0 → `I = 0`
- X、Y 强依赖 → 真实联合离"独立假说"很远 → KL 大 → `I` 大

> **互信息 = "X 和 Y 相互关联"这个真相，距离"它们没关系"这个假说，有多远。**

## 七、串回你学过的

| 你学过的 | 互信息给的统一视角 |
|---------|------------------|
| 决策树选特征（ID3） | 每个候选特征算 `I(标签; 特征)`，**挑互信息最大的那个**先分裂 |
| 特征选择 | 去掉那些和标签互信息接近 0 的"纯噪声特征" |
| 相关性 | 互信息是**非线性**版的相关系数——线性不够时还能抓非线性关系 |
| MLE / KL | 串回上一站的 KL 散度（同一套工具） |

**一句话：特征选择、决策树都在挑"和答案互信息大的信息源"。**

---

## 八、一句话总结

**单看熵不够——它不回答"有多少是新的"。条件熵 `H(X|Y)` = 知道 Y 后 X 的剩余不确定性；互信息 `I(X;Y) = H(X)−H(X|Y)` = Y 给 X 提供的信息，等价于 `KL(P_xy ‖ P_x·P_y)`，即"真实联合 vs 独立假说差多远"。特征选择、决策树都在挑互信息大的信息源。**

## 九、自测题

1. `H(X|Y)` 什么时候等于 `H(X)`？什么时候等于 0？
2. 互信息为什么是非负的？和 KL 散度是什么关系？
3. 为什么决策树（ID3）按特征选分裂时挑互信息最大的那个？
4. 互信息能抓到非线性关系吗？和皮尔逊相关系数比有什么好处？

（答案：1. Y 与 X 无关时 = H(X)；Y 完全决定 X 时 = 0。2. 因为 `I = KL(P_xy‖P_xP_y) ≥ 0`，KL 非负。3. 因为挑 `I(标签;特征)` 最大的特征分裂，能最快降低标签的不确定性。4. 能。互信息衡量任意依赖关系，皮尔逊只捕捉线性关系。）
