# 连续熵与微分熵 (Differential Entropy)

> 一句话定位：把离散熵推广到连续量。微分熵 `h(X) = ∫ f(x)·(-log₂ f(x)) dx` 是连续数据的"相对"信息量（差一个刻度常数），可以为负。正态是给定方差下微分熵最大、也即"信息量最大"的分布——这是正态"为什么无处不在"的信息论解释（最大熵原理）。
> 前置阅读：`information-theory.md`（熵）、`data-compression-shannon-coding.md`（压缩下限）、`statistical-inference/probability-distributions.md`（正态分布）。
> 串回：正态分布、压缩、最大熵原理、PCA/降维。

---

## 一、桥：连续分布不能直接套离散熵

离散熵是 `H(X) = Σ p(x)·(-log₂ p(x))`。但连续量（身高、电压、误差）没法"逐点列出概率"——概率分布篇讲过：`P(X = 恰好某值) = 0`。

连续量的熵怎么定义？**用极限逼近**：把连续区间切成很多小段，每段当"一个离散取值"，算离散熵，再让段长缩到 0。

---

## 二、把连续量切成小段

假设 X 是连续量，密度函数 `f(x)`。把取值范围切成宽度 `Δ` 的小段，第 `i` 段是 `[iΔ, (i+1)Δ)`。

这一段"被命中的概率"约等于 `f(x)·Δ`（密度×宽度），这就是一个"离散取值"的概率：

```
p_i ≈ f(x_i) · Δ        ← 第 i 段缩成一个点 x_i 处的高度 × 宽度
```

用离散熵公式：

```
H(离散近似) = Σ p_i · (-log₂ p_i)
            = Σ [f(x_i)·Δ] · (-log₂(f(x_i)·Δ))
```

---

## 三、拆分对数，看出"那一坨"

把 `-log₂(f(x_i)·Δ)` 用对数乘法拆开：

```
-log₂(f(x_i)·Δ) = -log₂ f(x_i) - log₂ Δ

代回：
H ≈ Σ [f(x_i)·Δ]·(-log₂ f(x_i))  −  Σ [f(x_i)·Δ]·(log₂ Δ)
```

- **第一项**：Σ f·Δ·(-log f)，在 Δ→0 时积分变成 **`∫ f(x)·(-log₂ f(x)) dx`** —— 这就是**微分熵**。
- **第二项**：Σ f·Δ = 1（密度积分 = 1），所以 = **`-log₂ Δ`**。段切得越细（Δ 越小）这一项越大——是发散的（Δ→0 时 `-log Δ → +∞`）。

---

## 四、微分熵的定义，以及"为什么它可以是负的"

舍掉那个发散项，定义**连续熵 / 微分熵**：

```
h(X) = ∫ f(x) · (-log₂ f(x)) dx
```

看着和离散熵几乎一样，只是 Σ→∫、p(x)→f(x)。但关键在于离散熵有"个数"的边界，微分熵没有——所以：

- 离散熵 `H ≥ 0` 永远非负
- 微分熵 `h` **可以为负**（某段密度 > 1 时，`-log f < 0`）——不可怕，因为微分熵是个**相对量**，不是"绝对信息量"

> 直觉区分：离散熵是"最少几比特"，微分熵是"用多细的刻度能描述"，中间那个发散的 `-log Δ` 被"刻度的粗细"吃掉了。所以微分熵永远差一个刻度常数。

---

## 五、正态分布的微分熵

算正态 `f(x) = 1/√(2πσ²)·exp(-(x-μ)²/(2σ²))` 的微分熵，结果很简洁：

```
h(X) = ½ log₂(2πeσ²)
```

三个观察：

- **μ 不见了**——平移不改变信息量（中心在哪不影响"有多不确定"）
- **σ 在**——方差越大，微分熵越大（越分散越难压缩）✓
- **log σ²**——呼应压缩那站：σ 越大熵越大，需要越多比特

---

## 六、高斯是"最优概"分布（最大熵原理）

一个常被引用的漂亮结论：**给定方差 σ²，在所有连续分布里，正态分布的微分熵最大。**

```
对所有 f 满足 Var(f) = σ²，
  h(f) ≤ h(正态) = ½log₂(2πeσ²)
  当且仅当 f 就是正态时取等
```

**直觉**：如果只告诉你"数据方差是 σ²"、别的什么都不知道，那"最不武断 / 信息最少"的假设就是正态——它把"未知的不确定性"放到最大。这给了正态"为什么无处不在"一个信息论的解释（除了中心极限定理，这是第二个理由）。

## 八、一句话总结

**对离散量，熵是信息下限；对连续量，微分熵 `h = ∫ f·(-log f)` 是"相对"信息量（差刻度常数），可以为负。而正态恰好是给定方差下微分熵最大、也即"信息量最大"的分布——这是正态无处不在的信息论解释。**
