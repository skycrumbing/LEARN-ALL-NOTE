# 信息论视角看 loss——信息论单元收尾

> 一句话定位：一年前你问"为什么要最小化 loss、为什么分类用交叉熵回归用 MSE"。这一篇站在信息论高处把整个 loss 家族统起来：**所有常见的 loss，本质都是"模型分布与真实分布之间的距离 / 那份猜错代价"。**
> 前置阅读：`information-theory.md`（熵、交叉熵、KL）、`conditional-entropy-mutual-information.md`（互信息）、`differential-entropy.md`（微分熵）、`statistical-inference/mle.md`（NLL=loss）。
> 这是信息论单元的 **总结篇**，把前四篇收拢成一个整体。

---

## 一、回顾：我们已经有了哪些东西

信息论一路走来，攒下了这几个工具：

```
信息量   I(p) = -log p             单个结果值多少信息
熵       H = Σ p·(-log p)         平均信息量 / 压缩下限
交叉熵   H(p,q) = Σ p·(-log q)    用错的 q 度量真实 p 的代价
KL 散度  KL(p‖q) = H(p,q) - H(p)  纯猜错代价（最小化交叉熵即最小化 KL）
互信息   I(X;Y) = KL(P_xy‖P_x·P_y)  真实联合 vs 独立假说差多远
微分熵   h = ∫ f·(-log f)         连续量的相对信息量
```

**核心洞察只有一个**：KL 散度 = "真实分布 vs 模型分布差多远"。而"最小化 loss"从信息论看，就是**缩小这份差距**。

---

## 二、一张表：所有常见 loss 都是 KL / 距离

| 你学过的 loss | 信息论里的真身                               | 它最小化的是什么 |
|--------------|---------------------------------------|----------------|
| 分类交叉熵 | `H(p, q)`，p=标签(one-hot)，q=模型输出        | 等价于最小化 `KL(p‖q)`（熵 H(p) 是常数） |
| 回归 MSE | 高斯假设下的 NLL（`conditional-entropy` 4.4） | "假设高斯 + MLE" ⇒ MSE；也可看作"预测与真值的平方距离" |
| KL 散度本身 | 直接量两个分布差多远                            | 直接就是"猜错代价" |
| 负对数似然 NLL | `-Σ ln p(x\|θ)`                       | 让数据更可能出现（= 让 q 逼近真实现实 p） |

**规律**：凡是"分类"的 loss，都能写成某个**交叉熵 / KL**；凡是"回归"的 loss，都能理解成"假设高斯噪声后的负对数似然"。两者信息论本质都是 **KL：让模型分布去逼近真实分布**。

---

## 三、为什么"最小化 loss"从信息论看是"最小化猜错代价"

回顾最核心那条线：

```
最大化  ln L(θ)          MLE：让数据最可能出现
⟺ 最小化 -Σ ln p(x|θ)   负对数似然
⟺ 最小化 H(p, q)         交叉熵（分类）
⟺ 最小化 KL(p‖q)         KL = 交叉熵 − 熵（熵是常数，最小化等价）
```

所以：

- 分类模型想学的，就是让预测分布 `q` 越来越像真实的标签分布 `p`
- 每降一次 loss，就是在**缩小 `KL(标签‖预测)` 这份"猜错代价"**
- 数据越多，`平均 KL` 越小——模型学到的东西越接近真相

**"最小化 loss" = "最小化猜错代价"——这不是玄学，是信息论必然。**

## 四、把整个单元的图景立起来

把这个信息论单元连成一张图：

```
        ┌──────── 信息量 I = -log p  ────────┐
        │                                      │
        ▼                                      ▼
       熵 H ────────►  交叉熵 H(p,q)  ────►  KL(p‖q) = 纯猜错代价
        │                                        │
        ├─► 压缩下限（上一站）                     ▼
        ├─► 互信息 I = H(X)-H(X|Y)         机器学习 loss
        └─► 微分熵 h（连续量）            （让模型 q 逼近真实 p）
                 └─► 正态最大熵
```

一次自学闭环：**信息量 → 熵 → 交叉熵/KL → 互信息 → 压缩 → 微分熵 → 全串回"为什么 loss 是这么设计"**。

## 五、将"distance"补全：KL 不是唯一的"距离"，但它是"最合理"的

回顾一下我们见过 KL 的每处出现，都对应"用对数压出来的猜错代价"：

```
KL(p‖q) = Σ p(x) · log(p(x)/q(x))
        = Σ p · [log p - log q]      ← 每项都是"理想码长 − 实际码长"
        = H(p,q) - H(p)              ← 交叉熵减去熵 = 纯浪费
```

- 它 ≥ 0，等于 0 当且仅当 p = q
- 它不对称（`KL(p‖q) ≠ KL(q‖p)`），所以是"散度"不是"距离"
- 它是**从"信息/编码"角度唯一自然的损失**——因为 loss 的本质就是"我在这份数据上的平均码长 − 理想码长"

用一句话收整个单元：

> **所有机器学习的 loss，背后都是同一个信息论问题：让模型对数据的"描述代价"逼近理论下限（熵）。最小化 loss = 最小化 `KL(真实‖模型)` = 最小化那份猜错代价。**

## 六、下一个台阶（出信息论单元去哪）

信息论单元到此自成闭环，可以放心放下了。它的姊妹篇其实已经指向清楚的两条路：

1. **贝叶斯推断 / MAP**（MLE 姊妹篇）：MLE 第九节说"只给一个点估计、忽略不确定性"——贝叶斯就是补这一刀，给参数加先验、最大化后验。
2. **从信息论观点再看神经网络**（如果你回头刷 CV/ML）：你现在知道了 loss 的根，可以反过来理解"为什么 PINN 用 MSE、为什么分类头用 softmax+cross-entropy"。

## 七、自测题

1. 为什么"最小化交叉熵"等价于"最小化 KL"？
2. MSE 在信息论里怎么解释？
3. 为什么说 "KL 是猜错代价"？
4. 这个单元见了几个不同的"熵"？它们各自的作用？

（答案：1. 因为交叉熵 = 熵(H(p)) + KL(p‖q)，训练时熵项是常数，最小化交叉熵 ⟺ 最小化 KL。2. 假设真实 p 是高斯的负对数似然（NLL）；从距离看是预测与真值的平方距离。3. 因为 KL = Σ p·(理想码长 − 实际码长)，即"用模型 q 编码真实 p 比用 p 自身编码多花的比特"。4. 信息量/熵/交叉熵/条件熵/互信息/微分熵六种，分别回答单事件信息、平均信息、用错分布描述、给定另一变量后剩余、两变量共享信息、连续量信息。）
