# 信息论入门 (Information Theory Basics)

> 一句话定位：信息论回答"一个式子里为什么有 `ln`、有负号、为什么叫信息"。它从"越不可能越有信息"的直觉出发，一步步到熵、交叉熵、KL 散度——并解释机器学习 loss 的深层含义。
> 前置阅读：`statistical-inference/probability-distributions.md`（概率分布）、`statistical-inference/mle.md`（负对数似然=loss）。
> 串回：`machine-learning/neural-network-basics.md`、`cat-from-scratch.md` 里的交叉熵损失。

## 一、从直觉出发：越不可能，越有信息

想一个问题：哪种事件"信息量"更大？

```
A. 明天下雨（天气预报 90% 概率下雨）
B. 明天晴天（天气预报 10% 概率晴天）
```

直觉显然是 **B 更"出人意料"**，它传达的信息更多。

这个直觉就是整个信息论的种子：

> **一个事件越不可能发生，它一旦发生，带给你的信息量越大。**

反过来，一个必然事件（概率 = 1）几乎不告诉你任何信息——因为它已经在意料之中。

---

## 二、给这个直觉配一个数

我们想把"信息量"变成一个可计算的数。直觉要求它满足三条：

1. **概率越低，信息量越大**（即 `1/p` 越大，信息量越大）
2. **两个独立事件同时发生，信息量应相加**（明天下雨 + 股票涨，两条信息加一块）
3. **概率 1 的事件，信息量 = 0**

**对数天生满足 2 和 3**：

```
某一个事件的 信息量  I(p) = -log₂(p)
                               ↑  负号让 p 越大 I 越小
```

验证三条：

```
p 小   →  log(p) 是大负数  →  -log(p) 是大正数   ✓ 概率低信息量大
独立事件：I(p·q) = -log(p·q) = -log p - log q = I(p) + I(q)   ✓ 乘法变加法
p = 1  →  I(1) = -log(1) = 0                   ✓ 必然事件信息量 0
```

**为什么底数取 2**：直觉是"最少几次二分能确定这个事件"。比如 `p = 1/8`，`-log₂(1/8) = 3`，刚好是"3 次二选一问出结果"。

> 注：用 `ln`（自然对数）也完全行，只差一个常数倍。MLE 里用的是 `ln`，信息论里习惯用 `log₂`（单位叫"比特"）。

## 三、熵：平均信息量

### 3.1 从单事件到整个变量

上面算的是**单个事件**的信息量。但一个随机变量每条消息都不一样——我们想要的是：**平均下来，观察这个变量每次能获得多少信息量？**

这就是**熵**——把每种可能的信息量，按它的概率加权平均：

```
H(X) = Σ p(x) · (-log₂ p(x))
       ↑       ↑
       概率   该结果的信息量
```

### 3.2 用掷骰子验证直觉

先凭直觉判断两种骰子：

```
均匀骰子：1~6 各 1/6，每种出现都有点出人意料 → 熵应该大
灌铅骰子：80% 出 6，"出 6"几乎可预期 → 熵应该小
```

算给两种看：

```
均匀骰子  H = 6 × (1/6) × (-log₂(1/6)) = log₂(6) ≈ 2.58
灌铅骰子  H = 0.8·(-log₂ 0.8) + 5 × 0.04·(-log₂ 0.04)
             ≈ 0.258 + 0.93 ≈ 1.19
```

```
均匀骰子 2.58  >  灌铅骰子 1.19    ✓
```

**越确定，熵越低**，正合直觉。

### 3.3 熵 = 负对数似然的期望

熟悉的面孔出现了：**熵 = 负对数似然的期望**。把 MLE 里那个 `-Σ ln p` 拿过来，对**所有可能取值**（不是对现有样本）取平均，就是熵。它俩是同一棵树上的。

## 四、交叉熵：用"错误分布"去度量

现在有两个分布：真实分布 `p`（骰子真实偏重），和你以为的分布 `q`（你猜它是均匀的）。

**交叉熵**：用 `q` 来度量"p 的真实信息"，即"如果用 q 去压缩/描述 p，会付出多少代价"。

```
H(p, q) = Σ p(x) · (-log₂ q(x))
          ↑              ↑
      真实概率     用q算的信息量
```

它和熵的差别仅在于：**信息量是按错误的 `q` 算的，但出现的概率还是真实的 `p`。**

举例：真实骰子灌铅（p 高度集中），但你当成均匀（q 均匀）。

```
H(真实p)         ≈ 0.8·(-log₂ 0.8)+… ≈ 1.19           ← 熵：知道真相，代价最小
H(真实p, 均匀q)  = Σ p(x)·(-log₂(1/6)) = log₂ 6 ≈ 2.58 ← 交叉熵：猜错，代价大
```

**交叉熵 > 熵**。越猜错，交叉熵越大。它永远 ≥ 熵。

---

## 五、KL 散度：纯猜错代价

把两者放一起，差值就是"因为你用错的 `q` 而白白多花的代价"：

```
KL(p ‖ q) = H(p, q) − H(p)
          = Σ p(x) · [log₂ p(x) − log₂ q(x)]
```

回到骰子例子：

```
KL(灌铅 ‖ 均匀) = 2.58 − 1.19 = 1.39    ← 纯粹因为你猜错而多花的
```

KL 散度的性质：

- **KL ≥ 0，且只有当 p = q 时等于 0**（用对分布，一分钱不浪费）
- 它**不对称**：`KL(p‖q) ≠ KL(q‖p)`，所以叫"散度"不叫"距离"

## 六、串回机器学习 loss

把你学过的三件东西放一张表上：

| 你学过的 | 信息论给出的新名字 |
|---------|------------------|
| MLE 的 `-Σ y·ln p + (1-y)·ln(1-p)` | 二类交叉熵（两个伯努利分布的交叉熵） |
| 训练神经网络的 loss | 让模型预测 `q` 逼近真实标签 `p`，即最小化 `KL(p‖q)` |
| 求 loss 最小 | 最小化交叉熵 ⟺ 最小化 KL（因为熵这一项不随 `q` 变） |

**这就是为什么模型学到的 `q` 会越来越像真实的 `p`**——梯度下降在做的不是玄学，是**缩小 `KL(p‖q)` 这个"猜错代价"**。

---

## 七、一句话总结

**信息论从"越不可能越有信息"出发：给单事件配 `-log p` → 加权平均得熵 → 用错的分布算得交叉熵 → 两者之差是 KL 散度 = 纯猜错代价。机器学习学的"最小化交叉熵"，本质就是在最小化"猜错代价"。**

## 八、自测题

1. 一个六面均匀骰子的熵是多少？
2. 交叉熵为什么永远 ≥ 熵？
3. 为什么训练模型要最小化交叉熵 / KL？
4. `KL(p‖q)` 和 `KL(q‖p)` 相等吗？为什么？

（答案：1. `log₂6 ≈ 2.58`；2. 因为 KL ≥ 0，交叉熵 = 熵 + KL；3. 熵是常数，最小化交叉熵 ⟺ 最小化 KL = 缩小猜错代价；4. 不相等，KL 不对称，p、q 互换结果不同）
