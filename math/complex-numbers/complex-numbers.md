## 一、结论先行(三句话)

1. **复数 = 在实数基础上多一个"新单位" i,规定 $i^2 = -1$。** 所有实数运算规则照用,只是多一条铁律:遇到 $i^2$ 就换成 $-1$。
2. **复数 $z = x + iy$ 可以看成平面上的一个点 (x, y)**——加减是平移,乘法是"缩放 + 旋转"。这个几何视角把复数从"抽象符号"变成"看得见的工具"。
3. **复数最大的价值:它让 $e^x$、$\sin x$、$\cos x$ 这些函数在"整个平面"上都成立,并且有欧拉公式 $e^{i\theta} = \cos\theta + i\sin\theta$。** 它把指数、三角、旋转串成一家,也让泰勒展开的"收敛半径 = 到最近奇点的距离"变得完整。

一句话记住:**复数就是"二维的数"。** 实数是直线上的数,复数是平面上的数——多一个维度,多出一整个新世界。

## 二、为什么负数要开根号:数系的一次扩充

### 2.1 数是怎么一步步"不够用"的

回顾一下数的扩充史——每次都是"眼前这些数不够用了,才发明新的":

| 想要表达 | 发明了什么 | 例子 |
|---|---|---|
| 半个 | 分数 | $\frac{1}{2}$ |
| 欠账 | 负数 | $-3$ |
| 正方形对角线的长度 | 无理数 | $\sqrt{2}$ |
| **平方等于 −1 的数** | **虚数 i** | $i,\ i^2 = -1$ |

最后一行就是今天的主角。实数里**不存在**平方等于 $-1$ 的数:任何实数的平方都 $\ge 0$。可方程 $x^2 = -1$ 又确实需要一个解。数学家于是说:

> 允许一个"新的数" i,规定 $i^2 = -1$。

这就像当年把"√2"当数一样——一开始觉得抽象,用起来才发现自然。**这就是 i,叫虚数单位**;由它组合出来的 $x + iy$(x、y 是实数)叫**复数**。

### 2.2 先看看 i 的"脾气"

根据 $i^2 = -1$,算 i 的各次幂:

| 幂 | 值 | 怎么算的 |
|---|---|---|
| $i^0$ | 1 | 任何数的 0 次幂 |
| $i^1$ | i | 定义 |
| $i^2$ | -1 | 定义 |
| $i^3$ | -i | $i^2 \cdot i = -i$ |
| $i^4$ | 1 | $i^2 \cdot i^2 = (-1)(-1) = 1$ |
| $i^5$ | i | $i^4 \cdot i = i$ |

**规律:i 的幂每 4 个一循环**:1 → i → −1 → −i → 1 → …。记住这个周期,后面计算快很多。

### 2.3 为什么值得发明?两个理由

1. **解方程不再有死角**:$x^2 = -1$、$x^2 - 2x + 5 = 0$ 这些在实数里"无解"的方程,在复数里全有解。而且有个漂亮结论(代数基本定理):**任何一个 n 次方程,在复数里恰好有 n 个根(含重根)**——实数做不到这么干净的承诺。
2. **旋转和振荡的天然语言**:一个数乘 i,等于让它"转 90°"(第六节会证明)。交流电、波动、信号处理(FFT)里到处是旋转,所以复数成了它们最顺手的记号。

## 三、复数的加减乘除

复数记作 $z = x + iy$,其中:
- **实部** $\text{Re}(z) = x$;
- **虚部** $\text{Im}(z) = y$(注意:y 是实数,不带 i)。

**相等**:两个复数相等 ⟺ 实部相等**且**虚部相等。这是后面解方程、验算的基础。

### 3.1 加减:实部碰实部,虚部碰虚部

$$
(x + iy) \pm (u + iv) = (x \pm u) + i(y \pm v)
$$

**手算例 1**:$(2 + 3i) + (1 - 4i) = 3 - i$。

### 3.2 乘法:分配律展开,遇到 $i^2$ 就换成 −1

$$
(x + iy)(u + iv) = xu + xiv + iyu + iy\cdot iv = xu + i(xv + yu) + i^2\,yv
$$

**关键一步**:$i^2\,yv = -yv$,所以:

$$
\boxed{\ (x + iy)(u + iv) = (xu - yv) + i(xv + yu)\ }
$$

注意实部是 $xu - yv$(带**减号**),这是最容易算错的地方。

**手算例 2**:$(2 + 3i)(1 - 4i)$。

一步一步来(不许跳步):

$$
= 2\cdot 1 + 2\cdot(-4i) + 3i\cdot 1 + 3i\cdot(-4i)
= 2 - 8i + 3i - 12i^2
$$

$i^2 = -1$,所以 $-12i^2 = +12$:

$$
= 2 - 8i + 3i + 12 = (2 + 12) + (-8 + 3)i = 14 - 5i
$$

**手算例 3(解方程)**:解 $x^2 - 2x + 5 = 0$。

用求根公式:

$$
x = \frac{2 \pm \sqrt{(-2)^2 - 4\cdot 5}}{2} = \frac{2 \pm \sqrt{4 - 20}}{2} = \frac{2 \pm \sqrt{-16}}{2}
$$

$\sqrt{-16} = 4i$(因为 $(4i)^2 = 16i^2 = -16$),所以:

$$
x = \frac{2 \pm 4i}{2} = 1 \pm 2i
$$

**验算**(把 $1 + 2i$ 代回):

$$
(1+2i)^2 - 2(1+2i) + 5 = (1 + 4i + 4i^2) - 2 - 4i + 5
$$

$4i^2 = -4$,所以 $(1 + 4i - 4) = -3 + 4i$,加起来:

$$
(-3 + 4i) + (-2 - 4i) + 5 = (-3 - 2 + 5) + (4 - 4)i = 0 + 0i = 0 \quad ✓
$$

实部虚部一起归零,方程真的成立。

> 💡 记住"**带 i 和 不带 i 分开算**"这条主线:复数运算 = 实数运算规则 + 遇到 $i^2$ 换成 $-1$。除法稍微要一点技巧,第五节讲。

## 四、复平面:把数看成平面上的点

### 4.1 一数一点

$z = x + iy$ 对应平面上的点 **(x, y)**:

- **实轴**:横轴(就是平常的数轴);
- **虚轴**:纵轴;
- 实数 $x$ 是这条平面上 $y = 0$ 的线(所以实数是复数的特例)。

| 复数 | 平面上的点 | 位置 |
|---|---|---|
| $3 + 4i$ | (3, 4) | 第一象限 |
| $-2i$ | (0, -2) | 虚轴负半段 |
| $5$ | (5, 0) | 实轴上 |

### 4.2 加减法 = 向量平移

把 $z = x + iy$ 想成一个从原点出发的**箭头**(向量)。那么:

- $(x+iy) + (u+iv)$ = 两个箭头首尾相接(平行四边形法则);
- 减法 = 反向。

**手算例**:$(3 + 2i) + (1 - i) = 4 + i$——先向右 3 再向右 1,先向上 2 再向下 1,落点 (4, 1)。

### 4.3 乘法呢?——先卖个关子

乘法在"直角坐标"下看很别扭(第二节那个 $xu - yv$ 公式),但在"极坐标"下看就美了:乘一个复数 = **把这个点绕原点旋转,再按比例缩放**。为什么?第六节用极坐标和欧拉公式回答。

> 💡 复平面给了我们两副眼镜:直角坐标($x, iy$)适合做加减;极坐标(距离 + 角度)适合做乘除。同一只复数,两种看法,看问题用哪副。

## 五、共轭与模:除法的关键

### 5.1 共轭:关于实轴的镜子

$z = x + iy$ 的**共轭**是 $\bar{z} = x - iy$——虚部变号,几何上就是**关于实轴翻转**。

**手算**:$z = -2 + 7i \Rightarrow \bar{z} = -2 - 7i$。

### 5.2 模:到原点的距离

**模** $|z| = \sqrt{x^2 + y^2}$——就是点到原点的距离(勾股定理)。几何上,一个点离原点越远,它的模越大。

### 5.3 两个必背性质

**性质 1**:复数 × 自己的共轭 = 模的平方:

$$
z\cdot\bar{z} = (x + iy)(x - iy) = x^2 - ixy + ixy - i^2y^2 = x^2 + y^2 = |z|^2
$$

**性质 2**:模的平方 = $x^2 + y^2$(交叉项 $ixy$ 和 $-ixy$ 抵消掉了)。

**手算验证**:$z = 3 + 4i$,$\bar{z} = 3 - 4i$:

$$
z\bar{z} = 9 - 12i + 12i - 16i^2 = 9 + 16 = 25 = |z|^2
$$

$|z| = \sqrt{25} = 5$——正是 3-4-5 直角三角形的斜边。✓

### 5.4 除法:用共轭"有理化分母"

$z$ 除以 $w$,分母是复数不好算。**技巧:分子分母同乘分母的共轭**,分母就变成实数 $|w|^2$:

$$
\frac{x + iy}{u + iv} = \frac{(x + iy)(u - iv)}{(u + iv)(u - iv)} = \frac{(x + iy)(u - iv)}{u^2 + v^2}
$$

分子展开(乘法公式):

$$
(x + iy)(u - iv) = xu - ixv + iyu - i^2yv = (xu + yv) + i(yu - xv)
$$

所以:

$$
\boxed{\ \frac{x + iy}{u + iv} = \frac{xu + yv}{u^2 + v^2} + i\,\frac{yu - xv}{u^2 + v^2}\ }
$$

**手算例**:$\frac{1 + 2i}{3 - 4i}$。

分子分母同乘 $3 + 4i$($3-4i$ 的共轭):

$$
\frac{(1 + 2i)(3 + 4i)}{(3 - 4i)(3 + 4i)} = \frac{3 + 4i + 6i + 8i^2}{9 + 16} = \frac{3 + 10i - 8}{25} = \frac{-5 + 10i}{25}
$$

$$
= -\frac{5}{25} + \frac{10}{25}i = -0.2 + 0.4i
$$

**验算**(乘回去):

$$
(-0.2 + 0.4i)(3 - 4i) = -0.6 + 0.8i + 1.2i - 1.6i^2 = -0.6 + 2i + 1.6 = 1 + 2i \quad ✓
$$

## 六、极坐标与欧拉公式

### 6.1 极坐标:用"距离 + 角度"描述一个点

平面上每个点 (x, y),除了直角坐标,还能用两个数描述:

- **距离 r** = 到原点的距离 = $|z|$;
- **角度 θ**(辐角 $\arg z$)= 从正实轴逆时针转过来的角。

关系就是三角函数:

$$
x = r\cos\theta, \qquad y = r\sin\theta
$$

于是:

$$
\boxed{\ z = x + iy = r(\cos\theta + i\sin\theta),\qquad r = |z| = \sqrt{x^2 + y^2}\ }
$$

### 6.2 欧拉公式:指数和三角是一家

下面这个式子叫**欧拉公式**,是复数世界里最重要的等式:

$$
\boxed{\ e^{i\theta} = \cos\theta + i\sin\theta\ }
$$

**怎么来的?用泰勒展开推(直接复用泰勒笔记的结论)。** 把 $i\theta$ 代进 $e^z$ 的泰勒级数 $e^z = 1 + z + \frac{z^2}{2!} + \frac{z^3}{3!} + \cdots$(这个级数处处收敛,稍后第七节会讲):

$$
e^{i\theta} = 1 + i\theta + \frac{(i\theta)^2}{2!} + \frac{(i\theta)^3}{3!} + \frac{(i\theta)^4}{4!} + \frac{(i\theta)^5}{5!} + \cdots
$$

逐项算 i 的幂:$(i\theta)^2 = -\theta^2$、$(i\theta)^3 = -i\theta^3$、$(i\theta)^4 = \theta^4$、$(i\theta)^5 = i\theta^5$、……,代进去:

$$
= 1 + i\theta - \frac{\theta^2}{2!} - i\frac{\theta^3}{3!} + \frac{\theta^4}{4!} + i\frac{\theta^5}{5!} - \cdots
$$

**把实部和虚部分开**(第四节的主线:带 i 和不带 i 分开算):

$$
= \underbrace{\Big(1 - \frac{\theta^2}{2!} + \frac{\theta^4}{4!} - \cdots\Big)}_{\cos\theta \text{ 的级数}} + i\underbrace{\Big(\theta - \frac{\theta^3}{3!} + \frac{\theta^5}{5!} - \cdots\Big)}_{\sin\theta \text{ 的级数}}
$$

括号里正是 $\cos\theta$ 和 $\sin\theta$ 的泰勒级数(泰勒笔记第三节见过 $\sin x$ 的)。所以 $e^{i\theta} = \cos\theta + i\sin\theta$ ✓。**欧拉公式不是魔法,它只是泰勒级数把实部虚部一分开,自己就长出来了。**

### 6.3 欧拉公式的几何意义

$e^{i\theta}$ 是什么?由公式,$\cos\theta$ 和 $\sin\theta$ 恰好是单位圆上角度 θ 的坐标。所以:

> **$e^{i\theta}$ = 单位圆上的点,模为 1,辐角为 θ。乘一个 $e^{i\theta}$,就是把复数旋转 θ 角。**

### 6.4 乘法为什么是"缩放 + 旋转"

有了欧拉公式,复数的极坐标写法是 $z = re^{i\theta}$。两个复数相乘:

$$
r_1 e^{i\theta_1} \cdot r_2 e^{i\theta_2} = r_1 r_2\, e^{i(\theta_1 + \theta_2)}
$$

**模相乘,角度相加。** 这也可以用三角函数恒等式手推一遍(不依赖欧拉公式):

$$
(\cos\theta_1 + i\sin\theta_1)(\cos\theta_2 + i\sin\theta_2)
$$

展开、把实部虚部分开:

$$
= \underbrace{(\cos\theta_1\cos\theta_2 - \sin\theta_1\sin\theta_2)}_{\cos(\theta_1+\theta_2)} + i\underbrace{(\sin\theta_1\cos\theta_2 + \cos\theta_1\sin\theta_2)}_{\sin(\theta_1+\theta_2)}
$$

中间两个括号正是两角和的余弦、正弦公式。所以乘法的几何意义是:**先按 r₂ 缩放,再旋转 θ₂ 角。**

**手算例:i = e^{i\pi/2}(旋转 90°)**。那 $i^2$ 呢?

$$
i^2 = e^{i\pi/2}\cdot e^{i\pi/2} = e^{i\pi} = \cos\pi + i\sin\pi = -1 + 0 = -1
$$

**这就是 $i^2 = -1$ 的几何原因:转两次 90° = 转 180° = 翻面 = 乘以 −1。** 第五节那个"奇怪"的定义,在复平面上一目了然。

**再验一个**:$(1 + i) \cdot i$。$1+i$ 的模是 $\sqrt{2}$、辐角 45°,乘 i(转 90°)后应该模不变、辐角 135°:

$$
(1+i)\cdot i = i + i^2 = i - 1 = -1 + i
$$

$-1 + i$ 的模 $\sqrt{(-1)^2 + 1^2} = \sqrt{2}$ ✓,辐角 135° ✓。旋转 90° 验证成立。

### 6.5 欧拉恒等式:四个常数同框

取 $\theta = \pi$:

$$
e^{i\pi} = \cos\pi + i\sin\pi = -1 + 0 = -1
$$

移项得到**欧拉恒等式**:

$$
e^{i\pi} + 1 = 0
$$

把 $e$、$\pi$、$i$、$1$、$0$ 这五个看似不相干的常数放进了同一个等号。经常被当作"数学最美公式"。

## 七、复数指数 e^z:处处有定义

把欧拉公式推广到一般复数 $z = x + iy$:

$$
\boxed{\ e^{z} = e^{x + iy} = e^x \cdot e^{iy} = e^x(\cos y + i\sin y)\ }
$$

### 7.1 这个式子告诉我们的

- **对任意复数 z,右边都有定义**——$e^x$ 是普通实数指数,$\cos y$、$\sin y$ 是普通三角函数。没有任何"爆炸"的点。
- **模只取决于实部**:$|e^z| = e^x$(因为 $|\cos y + i\sin y| = 1$);
- **周期性**:$e^{z + 2\pi i} = e^z$(虚部 y 每转一整圈,回到原处)。实数指数函数不是周期的,复数版本反而有了周期 $2\pi i$。

**手算例**:$e^{1 + i\pi} = e^1(\cos\pi + i\sin\pi) = e(-1) = -e \approx -2.718$。

### 7.2 为什么这点对泰勒那么重要

泰勒笔记里反复说 "eˣ 在复平面上没有任何奇点"。现在有了 $e^z = e^x(\cos y + i\sin y)$ 这个显式公式,就能真正看懂:

- $e^z$ 对**每个**复数 z 都有定义、处处可导(复可导);
- 没有一处"分母为零""对数取 0"之类的爆炸点;
- 所以离展开点最近的奇点不存在 → 收敛半径 = ∞ → **处处可展开**。

这是第七节的引子,第八节把所有线索串起来。

## 八、串回泰勒:奇点在复平面,现在看懂了

### 8.1 回顾泰勒笔记的结论

泰勒笔记第五节给了一条核心公式:

$$
\text{收敛半径} = \text{展开点到最近奇点的距离}
$$

而且强调**这个距离是在复平面上量的**。当时是"凭直觉接受",现在有了复数工具,可以真正算、真正看懂。

### 8.2 逐个看那几个例子

**例 1:$1/(1-x)$,奇点在 x=1。**

$x=1$ 处分母为 0(极点),距展开点 0 的距离是 $|1 - 0| = 1$。所以 R = 1。这个奇点在实轴上,**看得见**。

**例 2:$1/(1+x^2)$,奇点在 ±i——实轴上看不见。**

实轴上分母永远 $\ge 1$,光滑得很。但**在复平面**上:

$$
x^2 + 1 = 0 \quad\Longrightarrow\quad x = \pm i
$$

$\pm i$ 距原点多远?$|i| = \sqrt{0^2 + 1^2} = 1$,$|-i| = 1$。**所以 R = 1。** 泰勒笔记里"奇点藏在虚轴上"的说法,现在可以亲手算出那个距离了。

**例 3:$e^x$,没有奇点。**

第七节的 $e^z = e^x(\cos y + i\sin y)$ 对任意 z 有定义,复平面上不存在任何"爆炸点",所以 R = ∞。**"墙"不存在,信号想传多远都行。**

**例 4:$\ln(1+x)$,奇点在 x=-1。**

$\ln 0$ 无定义,所以 $x = -1$ 是奇点,距 0 为 1 → R = 1。$\sqrt{1+x}$ 同理($x=-1$ 处根号变号,是"支点"),R = 1。

### 8.3 为什么"实轴光滑"骗不了收敛半径

| 函数 | 实轴上看 | 复平面上看 | 半径 |
|---|---|---|---|
| $1/(1-x)$ | 在 x=1 爆炸 | 奇点 x=1(实轴上) | 1 |
| $1/(1+x^2)$ | 处处光滑 | 奇点 ±i(虚轴上) | 1 |
| $\arctan x$ | 处处光滑 | 奇点 ±i | 1 |
| $e^x$ | 处处光滑 | 无奇点 | ∞ |

**复平面把"看不见的墙"变成了"看得见的点"。** 收敛半径不是在实轴上"沿途找障碍",而是看**直线方向上最近的那堵墙**——而这个方向是复平面上的方向。这就是为什么泰勒笔记的核心答案,必须站在复平面才能讲完整。

## 九、应用与跨学科串联

### 9.1 FFT:复数指数是傅里叶的数学内核

傅里叶变换的本质,是把信号分解成无数个"旋转的复数指数"的叠加:

$$
x(t) = \sum_k X_k\, e^{i2\pi k t / T}
$$

每个 $e^{i2\pi kt/T}$ 就是单位圆上匀速旋转的点。为什么"匀速旋转"?拆开看:

- **单位圆**:欧拉公式说 $e^{i\theta} = \cos\theta + i\sin\theta$,而 $\cos^2\theta + \sin^2\theta = 1$,所以**模恒为 1**——$e^{i\theta}$ 永远在单位圆上,位置只由角度 θ 决定;
- **匀速**:把 t 当时间,这里的角度 $\theta = \frac{2\pi k}{T}t$。t 每走一步,θ 就走固定的一步(角速度 $\frac{d\theta}{dt} = \frac{2\pi k}{T}$ 是常数)——**等时间走等角度,就是"匀速"**;
- **转几圈**:t 从 0 走到 T,θ 从 0 走到 $2\pi k$——k=1 正好一圈,k=2 转两圈,k 越大转得越快。

看 k=1、T=1 的实例(每隔 1/8 个周期记一个点):

| t | θ = 2πt | 点 $e^{i\theta} = \cos\theta + i\sin\theta$ |
|---|---|---|
| 0 | 0 | $(1, 0) = 1$ |
| 1/8 | π/4 | $(\frac{\sqrt2}{2}, \frac{\sqrt2}{2})$ |
| 1/4 | π/2 | $(0, 1) = i$ |
| 1/2 | π | $(-1, 0) = -1$ |
| 1 | 2π | $(1, 0) = 1$(转满一圈,回到原点) |

等的时间间隔 → 等的角度间隔(每步都是 π/4),所以是"匀速旋转"。FFT 能高效算出这些系数,全靠复数的"旋转"视角。学了复数再看 [`FFT 笔记`](../../computer/communications/fft-digital-signal.md),很多式子会突然有了画面。

### 9.2 泰勒/幂级数:复平面的奇点决定半径

本篇第八节 + [`泰勒展开`](../taylor-series/taylor-expansion.md):收敛半径 = 展开点到最近复奇点的距离。**复数是"为什么幂级数只在一段有效"的最终答案。**

### 9.3 物理:交流电与波动

- 交流电路用**复数阻抗**($Z = R + iX$)统一描述电阻/电容/电感,欧姆定律、相角全用复数算;
- 波函数、电磁波里到处是 $e^{i(kx - \omega t)}$;
- 量子力学的波函数也写成一个复数指数。

### 9.4 方程与代数基本定理

**任何 n 次方程在复数里恰好有 n 个根**(含重根)。实数里"无解"的 $x^2 + 1 = 0$、$x^2 + 4x + 13 = 0$,在复数里都有解。这是复数的"完整世界"承诺。

### 9.5 旋转的记号

2D 旋转矩阵和复数乘法是同构的:乘 $e^{i\theta}$ 就是旋转 θ。很多图形学、机器人学(仓库里 [`nanometer-precision-math.md`](../../physics/mechanical/nanometer-precision-math.md) 的旋转矩阵)的旋转,复数都能给出一套更紧凑的写法。

## 十、自测题(含答案)

**1.** 计算 $(2 - 3i) + (-1 + 5i)$。

> **答案**:$(2-1) + (-3+5)i = 1 + 2i$。

**2.** 计算 $(1+i)(1-i)$。

> **答案**:$1 - i + i - i^2 = 1 - (-1) = 2$——两个共轭复数相乘得到纯实数(模的平方)。

**3.** 计算 $\frac{3+2i}{1-i}$。

> **答案**:分子分母同乘 $1+i$:$\frac{(3+2i)(1+i)}{(1-i)(1+i)} = \frac{3 + 3i + 2i + 2i^2}{1+1} = \frac{3 + 5i - 2}{2} = \frac{1 + 5i}{2} = 0.5 + 2.5i$。

**4.** $z = -2 + 7i$,求 $\bar{z}$ 和 $|z|$。

> **答案**:$\bar{z} = -2 - 7i$;$|z| = \sqrt{4 + 49} = \sqrt{53}$。

**5.** 用欧拉公式算 $e^{i\pi/2}$、$e^{i\pi}$、$e^{i\cdot 3\pi/2}$。

> **答案**:$\cos\frac{\pi}{2} + i\sin\frac{\pi}{2} = i$;$\cos\pi + i\sin\pi = -1$;$\cos\frac{3\pi}{2} + i\sin\frac{3\pi}{2} = -i$。三个点正好是单位圆上的四分之一圈、半圈、四分之三圈。

**6.** $e^{2 + 3i}$ 的模是多少?

> **答案**:$|e^{2+3i}| = e^2$(模只取决于实部,虚部只负责旋转)。

**7.** 解 $x^2 + 4x + 13 = 0$。

> **答案**:$x = \frac{-4 \pm \sqrt{16 - 52}}{2} = \frac{-4 \pm \sqrt{-36}}{2} = \frac{-4 \pm 6i}{2} = -2 \pm 3i$。

**8.** 用复数回答:为什么 $\frac{1}{1+x^2}$ 在实轴处处光滑,收敛半径却只有 1?

> **答案**:它的奇点在复平面 $x = \pm i$(满足 $x^2 + 1 = 0$),距展开点 0 的距离 $|\pm i| = 1$。实轴上看不见,复平面上看得见——这就是收敛半径 = 1 的原因。

---

> **一句话总结**:复数是"二维的数"——加一个规定 $i^2 = -1$ 的新单位,所有实数运算规则照用;把它看成平面上的点,加减是平移、乘法是旋转 + 缩放;而 $e^{i\theta} = \cos\theta + i\sin\theta$ 让指数、三角、旋转串成一家。最后它回答了泰勒留下的悬念:收敛半径的"墙"不在实轴上,而在复平面上——看不见,但复数让它看得见。
