# 系统设计 (System Design)

> 学习目标：通过真实业务场景，掌握高并发、高可用、一致性系统的架构设计方法。

## 学习内容

- [x] 支付账户系统：复式记账、分层架构、流水表设计、幂等
- [x] 秒杀商城：高并发与库存一致性、异步通知、大文件导出
- [x] 物联网服务器：千万级长连接的接入与架构（DNS/L4 分流、LVS、C10M）
- [x] 单点登录（SSO）：认证/授权分离、统一账号、每系统独立 RBAC、用户创建
- [x] OA 流程系统：三层分离、会签完成度算法、BPMN、超时处理、撤回转交
- [ ] 分布式系统通用理论（一致性、容灾、容量估算）
