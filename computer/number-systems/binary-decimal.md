# 二进制与十进制互转 & 十六进制存在的意义

## 二进制 → 十进制（按权展开法）

从右往左，每一位的权重是 $2^0, 2^1, 2^2, 2^3 \dots$

**公式**：`∑ (每一位数字 × 2^权重)`

### 示例：1011₂ → 十进制

```
1×2³ + 0×2² + 1×2¹ + 1×2⁰
= 8 + 0 + 2 + 1
= 11₁₀
```

### 示例：11010₂ → 十进制

```
1×2⁴ + 1×2³ + 0×2² + 1×2¹ + 0×2⁰
= 16 + 8 + 0 + 2 + 0
= 26₁₀
```

### 含小数的二进制 → 十进制

小数点左边同整数部分，右边依次是 $2^{-1}, 2^{-2}, 2^{-3} \dots$

**示例**：`101.101₂` → 十进制

```
整数部分：1×2² + 0×2¹ + 1×2⁰ = 4 + 0 + 1 = 5
小数部分：1×2⁻¹ + 0×2⁻² + 1×2⁻³ = 0.5 + 0 + 0.125 = 0.625
结果：5.625₁₀
```

## 十进制 → 二进制（除2取余法）

不断除以 2，记录余数，从下往上读。

### 示例：13₁₀ → 二进制

```
13 ÷ 2 = 6 余 1  ↑
 6 ÷ 2 = 3 余 0  |
 3 ÷ 2 = 1 余 1  |
 1 ÷ 2 = 0 余 1  |
```

从下往上：**1101₂**

验证：$8 + 4 + 0 + 1 = 13$ ✅

### 除2取余法的原理

为什么不断除以 2 再取余数就能得到二进制表示？

核心思路：**把十进制数拆成 2 的幂之和。**

任何一个整数都可以写成：
$$N = d_n \times 2^n + d_{n-1} \times 2^{n-1} + \dots + d_1 \times 2^1 + d_0 \times 2^0$$

其中 $d_n, d_{n-1}, \dots, d_0$ 就是二进制位（0 或 1）。

**关键观察**：除以 2 时：
- 余数 $d_0$ 是 $N \div 2$ 的余数（因为 $2^0$ 项是唯一不能被 2 整除的）
- 商是 $N \div 2 = d_n \times 2^{n-1} + d_{n-1} \times 2^{n-2} + \dots + d_1 \times 2^0$，再除以 2 时余数就是 $d_1$

**逐步推导**：

以 $13_{10}$ 为例：

```
13 = 1×2³ + 1×2² + 0×2¹ + 1×2⁰
   = 8 + 4 + 0 + 1

13 ÷ 2 = 6 余 1
```
- 余数 1 就是 $d_0$（$2^0$ 的系数）
- 商 6 去掉了 $2^0$ 项，相当于把整个数右移了一位

```
6 ÷ 2 = 3 余 0
```
- 余数 0 就是 $d_1$（$2^1$ 的系数）

```
3 ÷ 2 = 1 余 1
```
- 余数 1 就是 $d_2$

```
1 ÷ 2 = 0 余 1
```
- 余数 1 就是 $d_3$

**所以这个过程本质上就是：从最低位开始，逐位提取二进制系数。**

### 示例：42₁₀ → 二进制

```
42 ÷ 2 = 21 余 0
21 ÷ 2 = 10 余 1
10 ÷ 2 =  5 余 0
 5 ÷ 2 =  2 余 1
 2 ÷ 2 =  1 余 0
 1 ÷ 2 =  0 余 1
```

从下往上：**101010₂**

验证：$32 + 0 + 8 + 0 + 2 + 0 = 42$ ✅

### 十进制小数 → 二进制（乘2取整法）

不断乘以 2，取出整数部分，从上往下读。

**示例**：`0.625₁₀` → 二进制

```
0.625 × 2 = 1.25 → 取出 1  ↓
0.25  × 2 = 0.5  → 取出 0  |
0.5   × 2 = 1.0  → 取出 1  |
```

从上往下：**0.101₂**

验证：$0.5 + 0 + 0.125 = 0.625$ ✅

### 乘2取整法的原理

与除2取余法对称，小数部分要拆成 $2^{-1}, 2^{-2}, 2^{-3} \dots$ 的加权和：

$$F = d_{-1} \times 2^{-1} + d_{-2} \times 2^{-2} + d_{-3} \times 2^{-3} + \dots$$

其中 $d_{-1}, d_{-2}, d_{-3} \dots$ 就是二进制小数位。

**关键观察**：乘以 2 时：
- 整数部分就是 $d_{-1}$（因为 $2^{-1} \times 2 = 2^0 = 1$，这一项被"顶"到了整数位）
- 剩下的小数部分继续乘以 2，提取 $d_{-2}$

**逐步推导**：

以 $0.625_{10}$ 为例：

```
0.625 = 1×2⁻¹ + 0×2⁻² + 1×2⁻³
      = 0.5 + 0 + 0.125

0.625 × 2 = 1.25
```
- 整数部分 1 就是 $d_{-1}$（$2^{-1} \times 2 = 1$，被提取出来了）
- 剩下 0.25 继续

```
0.25 × 2 = 0.5
```
- 整数部分 0 就是 $d_{-2}$

```
0.5 × 2 = 1.0
```
- 整数部分 1 就是 $d_{-3}$

**所以乘2取整法本质上就是：从小数点后第一位开始，逐位提取二进制系数。**

## 为什么 0.1₁₀ 在二进制中是无限循环小数？

### 核心原因：分母不兼容

一个十进制小数能否用**有限**二进制表示，取决于它化简后的分母是否只包含质因数 **2**。

| 进制 | 基数 | 质因数分解 | 能精确表示的分母 |
|------|------|-----------|-----------------|
| 十进制 | 10 | $2 \times 5$ | 只含 2 和 5 的（如 $2, 4, 5, 8, 10$） |
| 二进制 | 2 | $2$ | 只含 2 的（如 $2, 4, 8, 16, 32$） |

$0.1_{10} = \frac{1}{10}$，分母 $10 = 2 \times 5$，含有质因数 **5**，二进制无法有限表示。

### 类比：十进制中的 $\frac{1}{3}$

就像 $\frac{1}{3}$ 在十进制中是 $0.333...$ 无限循环一样：

- 十进制能有限表示分母只含 2 和 5 的数
- 二进制能有限表示分母只含 2 的数
- $\frac{1}{10}$ 的分母有 5，所以二进制只能无限循环

### 实际计算：乘2取整法算 0.1₁₀

```
0.1 × 2 = 0.2 → 取出 0
0.2 × 2 = 0.4 → 取出 0
0.4 × 2 = 0.8 → 取出 0
0.8 × 2 = 1.6 → 取出 1，剩下 0.6
0.6 × 2 = 1.2 → 取出 1，剩下 0.2  ← 回到 0.2！开始循环
0.2 × 2 = 0.4 → 取出 0
0.4 × 2 = 0.8 → 取出 0
0.8 × 2 = 1.6 → 取出 1
0.6 × 2 = 1.2 → 取出 1
... 不断重复 0011 循环 ...
```

结果：$0.1_{10} = 0.00011001100110011...\ _2$（循环节 0011）

### 实际后果

这就是为什么在编程中 `0.1 + 0.2 ≠ 0.3`：

```python
>>> 0.1 + 0.2
0.30000000000000004  # 不是精确的 0.3！
```

计算机存储空间有限（如 64 位浮点数），只能在某一位截断，所以 $0.1$ 在内存里存的是**近似值**。

| 数字 | 二进制表示 | 精确？ |
|------|-----------|--------|
| 0.5 | `0.1₂` | ✅ 精确 |
| 0.25 | `0.01₂` | ✅ 精确 |
| 0.125 | `0.001₂` | ✅ 精确 |
| 0.1 | `0.000110011...₂` | ❌ 无限循环 |
| 0.2 | `0.00110011...₂` | ❌ 无限循环 |

## 为什么要有十六进制？

### 核心原因：二进制对人类太不友好

| 对比 | 同一个数 | 可读性 |
|------|----------|--------|
| 二进制 | `11111111` | ❌ 容易看花眼 |
| 十进制 | `255` | ✅ 日常 |
| 十六进制 | `FF` | ✅ 简洁 |

### 好处一：紧凑

- 1 位十六进制 = 4 位二进制
- 长度只有二进制的 1/4
- 8 位二进制（1 字节）= 2 位十六进制

### 好处二：转换无需计算

因为 $16 = 2^4$，每 4 位二进制直接对应 1 位十六进制：

```
二进制：   1011 | 1100
十六进制：   B  |  C    →  BC₁₆
```

不需要任何算术运算，查表即可：

| 二进制 | 十六进制 | 二进制 | 十六进制 |
|--------|----------|--------|----------|
| 0000 | 0 | 1000 | 8 |
| 0001 | 1 | 1001 | 9 |
| 0010 | 2 | 1010 | A |
| 0011 | 3 | 1011 | B |
| 0100 | 4 | 1100 | C |
| 0101 | 5 | 1101 | D |
| 0110 | 6 | 1110 | E |
| 0111 | 7 | 1111 | F |

### 好处三：计算机底层天然契合

- **内存地址**：`0x7FFF` 比 `0111111111111111` 容易记
- **颜色值**：`#FF0000`（红色）一目了然
- **权限**：`chmod 755`（本质是每 3 位二进制 = 1 位八进制）
- **MAC 地址**：`00:1A:2B:3C:4D:5E`
- **字节表示**：1 字节总是 2 个十六进制位

### 一句话总结

> 计算机用二进制，但人类读写二进制太容易出错，所以用十六进制作为"人类友好的二进制简写"。每 4 位二进制直接映射为 1 位十六进制，转换无需计算。
