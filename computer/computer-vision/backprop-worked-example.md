`cat-from-scratch.md` 是按**层**讲公式；这篇反过来，**跟住"一个参数"**走完正向和反向——因为反向传播的每一步，本质上都是在回答同一个问题："损失 L 对这一个参数有多敏感？"

---

## 〇、怎么读这篇：我们"跟住一个参数"

反向传播并不神秘：网络把数据往前推算出 `L`，反向就是把 `L` 顺着"谁影响了谁"的依赖链倒着分回去。**一次只跟住一个参数，这条链最清楚**。

我们从真实运行里挑**两个参数**当主角：

| 主角 | 是谁 | 依赖链长度 | 适合看清什么 |
|------|------|-----------|-------------|
| `b2[1]` | 猫类偏置（最后一层的常数项） | **3 跳**（最短） | 链式法则怎么一步步相乘 |
| `W1[0][0][0]` | 第一个卷积核的左上角权重 | **7 跳**（穿全部层） | 卷积权重为什么是"196 项累加"、ReLU/池化如何筛选 |

它们在网络里的位置（数据流向）：

```
16×16 灰度图 x
  ↓ ① 卷积（W1, b1）            ← ★ W1[0][0][0] 在这里（第一层）
  ↓ ② ReLU
  ↓ ③ 最大池化
  ↓ ④ 摊平  → f : 98 维
  ↓ ⑤ 全连接 z2 = W2·f + b2      ← ★ b2[1] 在这里（最后一层）
  ↓ ⑥ softmax → [P(非猫), P(猫)]
  ↓ ⑦ 交叉熵 → L
```

符号约定：`probs = [P(非猫), P(猫)]`；文档数字与日志一致（保留 3 位小数），`≈` 表示显示取整。

# 第一部分 · 最短链路：猫类偏置 `b2[1]`

## 1. 这个参数在网络里的位置

全连接层：$z2[k] = b2[k] + \sum_{b=0}^{97} W2[k][b]\cdot f[b]$。

`b2[1]` 只出现在**一个地方**——它是猫类得分 $z2[1]$ 的常数项。初始值：$b2[1] = 0$。

## 2. 正向：跟住 `b2[1]` 流到损失的 3 跳

**第 1 跳 · `b2[1]` → 猫得分 `z2[1]`**

$$z2[1] = b2[1] + \sum_{b=0}^{97} W2[1][b]\cdot f[b] = 0 + 0.047 = \boxed{+0.047}$$

> 那 98 项加权和 `Σ W2[1][b]·f[b] = 0.047` 是"其他 97 个参数"共同做的贡献；`b2[1]` 的贡献就是它自己 `0`。**看：这个参数只影响这一个小数。**

**第 2 跳 · `z2[1]` → 猫概率 `p1`（softmax）**

$$p_1 = \frac{e^{z_1-m}}{e^{z_0-m}+e^{z_1-m}} = \frac{1.0000}{1.9118} = \boxed{0.5231}$$

**第 3 跳 · `p1` → 损失 `L`（交叉熵）**

$$L = -\ln p_1 = -\ln(0.5231) = \boxed{0.6480}$$

**依赖链（这就是"一个参数的一生"）**：

$$
\boxed{\ b2[1] = 0 \ \longrightarrow\ z2[1] = +0.047 \ \longrightarrow\ p_1 = 0.5231 \ \longrightarrow\ L = 0.6480\ }
$$

## 3. 反向：错误怎么走回 `b2[1]`（链式法则 3 跳）

反向 = 顺着上面的链**倒着**走，每跳乘一个"局部导数"。目标是算 $\dfrac{dL}{db2[1]}$：

$$
\frac{dL}{db2[1]} = \underbrace{\frac{dL}{dp_1}}_{\text{第1跳}} \times \underbrace{\frac{dp_1}{dz_2[1]}}_{\text{第2跳}} \times \underbrace{\frac{dz_2[1]}{db2[1]}}_{\text{第3跳}}
$$

**第 1 跳 · L → p1：** $L = -\ln p_1$，所以

$$\frac{dL}{dp_1} = -\frac{1}{p_1} = -\frac{1}{0.5231} = -1.912$$

**第 2 跳 · p1 → z2[1]：** softmax 的导数（一个类对自身得分）

$$\frac{dp_1}{dz_2[1]} = p_1(1-p_1) = 0.5231 \times 0.4769 = 0.2495$$

**第 3 跳 · z2[1] → b2[1]：** $z2[1] = b2[1] + \text{(别的)}$，所以

$$\frac{dz_2[1]}{db2[1]} = 1$$

**乘起来：**

$$
\frac{dL}{db2[1]} = (-1.912) \times 0.2495 \times 1 = \boxed{-0.477}
$$

用"分锅表"看得更清楚（每个节点收到的梯度 = 上游 × 局部导数）：

| 节点 | 前向值 | 局部导数 | 收到的梯度 |
|------|--------|---------|-----------|
| L | 0.6480 | — | — |
| p1 | 0.5231 | $dL/dp_1 = -1.912$ | **−1.912** |
| z2[1] | +0.047 | $dp_1/dz_2[1] = 0.2495$ | −1.912 × 0.2495 = **−0.477** |
| b2[1] | +0.000 | $dz_2[1]/db2[1] = 1$ | −0.477 × 1 = **−0.477** |

> **捷径（为什么最终梯度恰好等于 −0.477）**：softmax 和交叉熵叠在一起时，导数可以合并成一个干净公式 $\dfrac{dL}{dz_2[k]} = p_k - \text{onehot}(y)_k$。对猫类：$0.5231 - 1 = -0.477$。这就是日志 ⑧-1 那个公式——**链式法则 3 跳相乘，和合并公式的结果完全一致**（$-\frac{1}{p_1}\times p_1(1-p_1) = -(1-p_1)$）。

**为什么是负的（你之前问过的）**：模型给猫类只打了 $0.5231$，而目标是 1——**欠了 $0.477$**。梯度取"实际 − 目标" $= 0.5231 - 1 = -0.477$。更新时 $-lr\times(-0.477) = +lr\times0.477$，正好把猫类抬上去。

## 4. 更新：`b2[1]` 走一步

$$b2[1] \leftarrow b2[1] - \eta\cdot\frac{dL}{db2[1]} = 0 - 0.030\times(-0.477) = \boxed{+0.014}$$

> 0 变成 +0.014：下一次前向，猫得分 $z2[1]$ 会凭空多 0.014 → 猫概率略升 → 损失略降。**这一个参数的"学习"，就是这一步。**训练 = 128 张样本 × 150 轮，把 218 个参数各自都这么走一遍。

## 5. 小结：这就是反向传播的全部

`b2[1]` 只有 3 跳，所以你能看清完整骨架。**网络里的每个参数，都有这么一条从自己通往 L 的链**——只是有些链更长、要穿过更多层。反向传播不是魔法，就是把这条链的每一跳导数乘起来：

$$
\text{梯度} = \prod_{\text{每一跳}} \text{局部导数}
$$

# 第二部分 · 最长链路：卷积权重 `W1[0][0][0]`

## 1. 这个参数在网络里的位置

`W1[0][0][0]` 是**第 0 个卷积核的左上角**，初始值 $-0.051$。它和 `b2[1]` 相反——在**第一层**，离损失最远，依赖链要穿过全部 7 步。

卷积公式：$z1[0][i][j] = b1[0] + \sum_{u,v} W1[0][u][v]\cdot x[i+u][j+v]$。

## 2. 正向：它同时影响 196 个输出位置

关键区别：`b2[1]` 只影响 1 个位置，而 `W1[0][0][0]` 因为卷积核**滑过全图**，在 $z1[0]$ 的**每一个** $(i,j)$（共 $14\times14=196$ 个）里都贡献一项：

$$
z1[0][i][j] = \cdots + \underbrace{W1[0][0][0]\times x[i][j]}_{\text{这一项}} + \cdots
$$

例：`z1[0][0][0]` 里那一项是 $-0.051\times0.066$，而 `z1[0][3][3]`（猫头区域，$x[3][3]=0.898$）里那一项是 $-0.051\times0.898$。**一个权重，插进了 196 个式子。**

## 3. 反向：一条穿全 7 层的长链

### 3.1 链路

$$
W1[0][0][0] \longrightarrow z1 \longrightarrow a1 \longrightarrow p1 \longrightarrow f \longrightarrow z2 \longrightarrow p \longrightarrow L
$$

### 3.2 用链式法则展开

因为 $W1[0][0][0]$ 出现在 196 个 $z1[0][i][j]$ 里，梯度要**对这 196 条路全部求和**：

$$
\boxed{\ \frac{dL}{dW1[0][0][0]} = \sum_{i=0}^{13}\sum_{j=0}^{13} \underbrace{\frac{dL}{dz1[0][i][j]}}_{\text{后 6 层传回来的梯度}} \times \underbrace{\frac{\partial z1[0][i][j]}{\partial W1[0][0][0]}}_{=\ x[i][j]} \ }
$$

其中 $\dfrac{\partial z1[0][i][j]}{\partial W1[0][0][0]} = x[i][j]$ 是从卷积公式直接求导得到的（那一项 $W1[0][0][0]\cdot x[i][j]$ 对 $W1[0][0][0]$ 求导就是 $x[i][j]$）。

直觉：**每个位置的梯度，乘上那个位置的输入像素，再全部累加。**

### 3.3 196 项里只有 47 项是"活"的

$\dfrac{dL}{dz1[0][i][j]}$ 就是 ⑧-5 的 `dz1[0][i][j]`。它在绝大多数位置都是 0，因为中间经过了**两道闸门**：

1. **池化反向**：每个 2×2 窗口只有最大值拿得到梯度 → $z1[0]$ 只有 49 个位置非零
2. **ReLU 反向**：$z1\le0$ 的梯度被杀 → 49 个里又死 2 个（日志里 $(0,8,2)$ 和 $(0,10,4)$）

所以 196 项里，**47 项非零、149 项是 $0\times x[i][j]=0$**。日志 ⑧-6 展开的前 9 项几乎全是 `+0.000×…`，就是这个原因。

$$
\frac{dL}{dW1[0][0][0]} = \underbrace{0.000\times0.066 + 0.000\times0.000 + \cdots}_{149\ \text{项是 }0} + \underbrace{(-0.005)\times0.000 + (-0.012)\times0.027 + \cdots}_{47\ \text{项是真的} } = \boxed{-0.054}
$$

### 3.4 和最短链路的对照

| | `b2[1]`（偏置） | `W1[0][0][0]`（卷积权重） |
|---|---|---|
| 出现在前向几次 | 1 次 | 196 次 |
| 梯度 = | 上游梯度 × 1 | 196 项求和 |
| 哪些项活着 | 全部 | 只有"池化选中 + ReLU 活着"的 47 项 |
| 梯度值 | −0.477 | −0.054 |

> **偏置的梯度最简单**（∂z/∂b = 1），**卷积权重的梯度最"重"**（要穿过池化/ReLU 两把筛子，还要把 196 个位置累加）。这是所有 CNN 反向传播的普遍规律，不只是这个小例子。

## 4. 更新：`W1[0][0][0]` 走一步

$$W1[0][0][0] \leftarrow -0.051 - 0.030\times(-0.054) = \boxed{-0.050}$$

> **显示取整的坑（值得记住）**：用日志里显示的值手算 $-0.051 - 0.030\times(-0.054) = -0.049$，会得到 $-0.049$，和日志的 $-0.050$ 差 0.001。原因是真实计算用**全精度**：$-0.05147 - 0.030\times(-0.05362) = -0.04986 \approx -0.050$。显示的 $-0.051$ 和 $-0.054$ 都四舍五入了。**别拿四舍五入的中间值去验算结果，会差 ±0.001。**

## 5. 一个参数一路涨成"特征检测器"

`W1[0][0][0]` 训练前后的变化（日志"参数快照"）：

| 阶段 | W1[0][0][0] |
|------|------------|
| 初始 | −0.051 |
| 第 1 步更新后 | −0.050 |
| epoch 50 | +0.247 |
| epoch 100 | +0.278 |
| 最终 | **+0.290** |

从负变正——它和其他 8 个权重一起，慢慢学会了"匹配亮像素"（猫头/耳朵是亮的）。**这就是"模型自动学特征"最微观的证据：一个数，被 128 张样本的梯度，一步步从 −0.051 推到 +0.290。**

# 第三部分 · 对账、鸟瞰与复现

## 7. 怎么确认上面全算对了

**数值梯度校验（finite difference，最硬核）**：导数的定义就是"抖一抖看变化率"。把每个参数的值 `±h` 抖动，重算两次前向和损失：

$$
\text{数值梯度} = \frac{L(w+h) - L(w-h)}{2h}\quad (h=10^{-5})
$$

和 `backward()` 算出的分析梯度对比。`code/_gradcheck.py` 对 6 个参数的真实运行结果（**误差全在 $10^{-12}$**）：

| 参数 | 分析梯度（backward） | 数值梯度（抖动测试） | 误差 |
|------|--------------------|--------------------|------|
| dW1[0][0][0] | −0.053617 | −0.053617 | 4.45e-12 |
| dW1[1][2][1] | −0.127256 | −0.127256 | 4.39e-12 |
| db1[0] | +0.130855 | +0.130855 | 5.38e-12 |
| dW2[0][0] | +0.012337 | +0.012337 | 4.22e-12 |
| dW2[1][50] | −0.171354 | −0.171354 | 3.33e-12 |
| db2[1] | −0.476923 | −0.476923 | 6.15e-12 |

> 这说明 `backward()` 从 softmax 到卷积的每一跳局部导数都写对了。任何一层符号写反，误差立刻跳到 $10^{-2}$。真实框架（PyTorch/TensorFlow）也用同样的校验测自己的 autograd。

## 8. 训练全貌：这一套参数最后学成了什么样

- **损失一路下降**：epoch 1 → 0.4853（准确率 76.6%），epoch 10 → 0.0167（100%），epoch 150 → 0.0002（100%）
- **测试集**（32 张从没见过的图）：准确率 **100%**，TP=16 / TN=16 / FP=0 / FN=0
- **彩蛋定位**：40×40 场景藏一只猫，滑动窗口找到 `P(猫)=1.00`，中心距 **0.0 像素** 🎯
- **最终偏置**：`b1 = [-0.332, +1.024]`，`b2 = [+1.429, -1.429]`——还记得 `b2[1]` 从 0 开始吗？150 轮后它长到 **+1.429**，模型"默认倾向猫"
