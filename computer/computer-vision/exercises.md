## 参考答案

### 一、概念辨析

1. 灰度图 = 二维数字矩阵（每格一个 0~255 亮度值）；RGB 彩色图 = 三个二维矩阵叠放（每像素一组 (R,G,B) 三值）。
2. OpenCV 是 **BGR**。直接用 matplotlib 显示会红蓝互换（天空变橙）。
3. ① 参数爆炸：全连接层权重数 = 输入像素数 × 神经元数，可达数亿；② 破坏空间结构：摊平成一条线后学不到"平移不变性"，同样的特征换个位置就被当成新东西。
4. 卷积核 = 特征检测器（找边缘/角点/纹理等局部模式）。K 个核 = 一层提取 K 种特征，得到 K 张特征图。
5. 池化 = 压缩 + 挑重点，减小尺寸、抗平移。Max Pooling 在窗口里取最大值（如 2×2 窗口取最大）。
6. 感受野 = 特征图上一点对应回原图的区域大小。越大能看到越多的上下文，深层网络靠它识别"整体"。
7. 分类：整张图一个类别；定位：一个物体 + 一个框；检测：多个物体 + 各自框和类别。
8. IoU ∈ [0, 1]。IoU=1 两框完全重合；IoU=0 完全不相交。
9. NMS 解决"同一个物体被框了很多次"的问题。步骤：按得分降序 → 取最高分保留 → 删除与其 IoU > 阈值的框 → 重复直到没有框。
10. 两阶段：先生成候选区域再细分类，准但慢、流程复杂；单阶段：一次回归直接输出，快（实时）、小物体稍弱。
11. 不是。检测 = 在哪（框）；识别 = 是谁（身份）。识别建立在检测之上。
12. embedding = 把人脸映射成高维向量，同类近、异类远。识别时算两个向量的余弦相似度，高于阈值判为同一个人。
13. ① 车牌检测（定位车牌）→ ②（可选）字符分割 → ③ 字符识别（OCR/LPRNet）。
14. CTC 解决"模型输出长度 ≠ 标签长度"的对齐问题。blank 表示"此刻没有字符"，训练时穷举所有对齐，解码时合并重复字符并去掉 blank。

### 二、计算题

**题 1**：$(32 + 2×2 - 5)/1 + 1 = 32$。输出仍是 32×32（padding 抵消了缩小）。

**题 2**：滑动 2×2 窗口求和：

```
窗口1(左上): 1+2+0+1 = 4    窗口2: 2+3+1+2 = 8   窗口3: 3+0+2+3 = 8
窗口4: 0+1+1+0 = 2          窗口5: 1+2+0+1 = 4   窗口6: 2+3+1+2 = 8
窗口7: 1+0+0+1 = 2          窗口8: 0+1+1+0 = 2   窗口9: 1+2+0+1 = 4

输出 =
[[4, 8, 8],
 [2, 4, 8],
 [2, 2, 4]]
```

**题 3**：

- A: x∈[1,5], y∈[1,4]；B: x∈[3,7], y∈[2,5]
- 交集: x∈[3,5]（宽2）, y∈[2,4]（高2）→ 面积 4
- A 面积 = 4×3 = 12；B 面积 = 4×3 = 12
- 并集 = 12 + 12 − 4 = 20
- IoU = 4/20 = **0.2**

**题 4**：

```
排序: 框1(0.9) → 框4(0.85) → 框2(0.75) → 框3(0.6)
第1轮: 取框1，保留。删掉与框1 IoU>0.5 的：框4(0.7>0.5 删)，框2、框3 保留。
第2轮: 剩下 [框2, 框3]，取框2(0.75) 保留。框3 与框2 IoU=0.0 ≤0.5 保留。
第3轮: 取框3，保留。

最终保留: 框1、框2、框3（框4 被删，因为和最高分框1 太重叠）
```

**题 5**：最终得分 = 0.7 × 0.8 = **0.56**。

### 四、开放题（要点提示）

1. 单阶段一次前向输出全部框，省去"候选区域生成 + 逐个分类"两套流程，所以快；两阶段对候选区精细分类回归，所以准。
2. 固定摄像头、蓝牌、光线可控 → 传统方法性价比最高；场景复杂（各种牌型、角度）→ 端到端 LPRNet / YOLO+OCR。要点：说出理由，没有唯一答案。
3. 依赖"特征提取 + 相似度阈值 + 活体检测"。照片/视频可骗过静态识别，活体检测（眨眼/摇头/3D）阻断这种攻击。
4. 最省事：直接用 YOLO 微调——收集一批"戴口罩/不戴口罩"的标注图，用预训练权重训练。要点：强调"预训练微调"而不是从零训练。
5. 最大短板：特征靠人设计，认不出人想不到的模式，泛化差。仍可用：规则固定、无 GPU、要求极快/极轻的场景（老式设备、边缘端）。
