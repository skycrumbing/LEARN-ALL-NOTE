## 一、直观理解：一条"越来越快、越来越聪明"的主线

回顾上一篇的两种范式。这条主线怎么来的？核心矛盾始终是：

```
计算机"不知道物体在哪" → 只能到处试
   ↓
  怎么"到处试"试得又准又省？  ← 所有算法的进化动力
```

历史演进分四代：

| 时代 | 代表 | 思路 | 快/慢 |
|------|------|------|-------|
| 传统手工特征 | Haar 级联、HOG+SVM | 人设计特征 + 滑动窗口 | 快但弱（只认特定物体） |
| 深度学习两阶段 | R-CNN → Fast → Faster | 深度特征 + 候选区域 | 准，慢 |
| 深度学习单阶段 | YOLO、SSD | 一步直接预测 | 快，用于实时 |
| 无锚框/Transformer | DETR | 直接集合预测 | 准，思路彻底变了 |

> **一句话主线：滑动窗口(笨办法) → 候选区域+深度CNN(准但慢) → 端到端回归(快) → 集合预测(优雅)。**

---

## 二、传统时代：滑动窗口 + 手工特征

### 滑动窗口（Sliding Window）

最朴素的想法：**把图切成很多小块，逐块判断"这是不是猫"**。这个"小块"就是滑动窗口。

```
┌─┬─┬─┬─┬─┐
│□│□│□│□│□│   ← 一个固定大小的窗口从左上角开始，
├─┼─┼─┼─┼─┤     从左到右、从上到下扫描，每格都判断一次
│□│□│□│□│□│
├─┼─┼─┼─┼─┤     猫可能有大有小 → 还要换不同大小的窗口再扫一遍
│□│□│□│□│□│     = 多尺度 × 全图 = 海量计算
└─┴─┴─┴─┴─┘
```

**缺点**：窗口个数爆炸。一张 640×480 的图 + 5 种尺寸 ≈ 上百万次判断，几乎不可行。

### Haar 级联（Viola-Jones，2001）：专门为"人脸"优化

Haar 用了一个聪明组合，让"到处试"变得可接受：

| 手段 | 做了什么 |
|------|---------|
| **Haar 特征** | 用几个固定的黑白矩形模板（如"眼睛区域比脸颊暗"）当特征，不用学 |
| **积分图** | 一个技巧让"任意矩形区域的亮度之和"一次算完，极快 |
| **级联分类器** | 几十个分类器串起来：前几层用最便宜的规则快速扔掉"明显不是脸"的区域，只有通过的才进下一层。**绝大多数区域在前几层就被淘汰**，所以快 |

```
候选区域 → [第1层 很便宜: 这是脸吗?] → 否→丢弃
                │是
                ↓
          [第2层 稍贵: 还是脸吗?] → 否→丢弃
                │是
                ↓
          ...... 通过全部层 → 判定为脸
```

> **Haar 的意义：证明了"滑动窗口 + 聪明裁剪"也能实时检测（当年 15fps 惊人）。** 缺点是只认人脸这类"结构规整"的物体，对猫、角度多变的车牌基本无能为力。你可以在 `04_haar_face_detect.py` 里亲身体验。

### HOG + SVM（2005）：行人检测

- **HOG（方向梯度直方图）**：统计图像局部区域"梯度方向"的分布，本质是描述"这一块的轮廓长啥样"。
- 配一个 **SVM**（支持向量机，你学过梯度下降可以联想）当分类器。
- 思路：手工特征 + 机器学习分类器，比 Haar 通用一点，但仍依赖人设计特征。

> **传统方法的共同天花板：特征是人设计的，人想不到的"猫"特征就认不出。深度学习的革命在于——让模型自己学特征。**

## 三、深度学习两阶段：R-CNN 家族

### R-CNN（2014）：深度特征 + 候选区域

第一次把 CNN 用进检测。三步：

```
① 候选区域生成(Selective Search)  ② 每个候选区送入CNN提特征  ③ SVM分类 + 回归精修框
  先用图像分割生成约2000个"可能    ┌─┐                        ┌──┐
  有物体的区域"（替代滑动窗口）    │①│→ 缩放到固定大小          │③│→ 输出"猫"+ 精确框
                                  └─┘→ ②CNN提特征             └──┘
```

**进步**：不用上百万个窗口，只用约 2000 个候选区；CNN 自动学特征。
**缺点**：2000 个候选区每个都要单独过一遍 CNN，**极慢**（一张图几秒）。

### Fast R-CNN（2015）：整张图只过一遍 CNN

关键优化：**全图只过一次 CNN，提取一次特征图**，所有候选区都在这张共享特征图上操作（ROI Pooling）。

```
全图 → 一次CNN → 特征图（全图共享）
                   ↑
       2000个候选区各自在共享特征图上取对应区域 → 分类 + 精修
```

速度大幅提升。**但候选区域生成（Selective Search）仍然是独立的慢步骤。**

### Faster R-CNN（2016）：候选区域也交给网络学

把候选区域生成也换成一个小网络 **RPN（Region Proposal Network）**，和主网络一起训练：

```
全图 → CNN特征图 ─┬→ RPN: 预测"哪里有物体"(候选框)
                  └→ ROI Pooling: 把候选框区域取出来 → 分类 + 精修

全流程端到端可训练。速度接近实时。
```

> **Faster R-CNN 奠定了"两阶段"的标准范式，此后多年是检测精度霸主。** 代价：两个阶段（RPN + 分类器）流程复杂、训练麻烦。

## 四、深度学习单阶段：YOLO 与 SSD

### 核心思想：把检测变成"一次回归"

YOLO 想的是：**为什么不能扫一眼整张图，直接一次性输出所有框和类别？**

做法：把图分成 S×S 网格，**每个网格负责预测中心落在它里面的物体**：

```
原图分成 7×7 网格
┌─┬─┬─┬─┬─┬─┬─┐
│ │ │ │ │ │ │ │
├─┼─┼─┼─┼─┼─┼─┤
│ │ │🐱│ │ │ │ │   ← 猫的中心落在这一格，由这一格负责
├─┼─┼─┼─┼─┼─┼─┤
│ │ │ │ │ │ │ │
└─┴─┴─┴─┴─┴─┴─┘

每个网格一次性输出：k个候选框(x,y,w,h) + 置信度 + 各类别概率
```

**YOLO 的输出就是一个大张量**，一次前向传播同时得到所有框和类别 → **快**（实时）。

**演进**：

| 版本 | 关键改进 |
|------|---------|
| YOLOv1 (2016) | 提出单阶段思路，快但定位糙（每格只负责一个物体） |
| YOLOv2/v3 | 引入锚框(anchor)、多尺度特征图(FPN)，小物体变好 |
| YOLOv5~v8 | 工程化成熟：好训练、快、社区生态大（你现在就能用） |

> **锚框（Anchor）**：预先定义一组"常见形状"的框（高瘦、矮胖、方），让网络去"微调"而不是凭空猜，收敛快很多。见 detection-concepts 里 IoU 那节——训练时锚框要和真实框算 IoU 来配对。

### SSD（2016）：多尺度特征图各层都检测

SSD 的思想：**不同尺度的特征图负责不同大小的物体**。

```
浅层特征图(大,细节多) → 检测小物体
深层特征图(小,语义强) → 检测大物体
```

> 既单阶段（快），又照顾小物体（准一点）。**浅层看细节、深层看整体**——和 CNN 笔记里"越深越抽象"完全呼应。

## 五、无锚框 + Transformer：DETR（2020）

DETR 把整个问题重新定义——**当成"集合预测"**，直接用 Transformer（你学过！）做：

```
CNN特征图 → 位置编码 → Transformer编码器-解码器 → 输出 N 个预测(框+类别)

   N个预测 → 用"匈牙利匹配"和真实框一一配对 → 算损失训练
```

**没有锚框、没有 NMS、没有候选区域**，一个模型从输入到输出。缺点：小物体检测弱、训练收敛慢（后来 Deformable DETR 改进）。

> **DETR 的意义：证明目标检测可以用"优雅的全局建模"替代"堆砌的工程技巧"。** 但工程上目前 YOLO 系列仍统治实时场景。

## 六、选型建议：什么时候用哪个

| 场景 | 推荐 | 原因 |
|------|------|------|
| 实时摄像头/自动驾驶 | YOLO | 快，能跟得上帧率 |
| 追求极致精度、物体少 | Faster R-CNN | 准 |
| 只检测人脸 | Haar / MTCNN / YuNet | 专任务专用，轻量 |
| 检测+识别车牌 | 专用 LPR 模型 | 见 license-plate 笔记 |
| 研究/通用建模 | DETR 系 | 思路优雅，新范式 |

> **工程上记住一条铁律：先跑通最成熟的（YOLO），再根据瓶颈换方案。** 别一上来就自己训练。

## 七、本篇一句话总结

| 阶段 | 核心思路 | 瓶颈 |
|------|---------|------|
| 滑动窗口+Haar | 手工特征 + 级联裁剪 | 只认特定物体 |
| R-CNN 系 | 候选区域 + 深度CNN | 慢→快，流程复杂 |
| YOLO/SSD | 一次回归直接输出 | 小物体弱 |
| DETR | Transformer 集合预测 | 训练收敛慢 |
