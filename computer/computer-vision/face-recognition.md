> 记录日期：2026-09-10

## 一、直观理解：先分清两个完全不同的问题

"人脸"这个词有两层含义，做之前必须分清，否则永远学不明白：

| | 人脸**检测** | 人脸**识别** |
|---|---|---|
| 回答的问题 | 图里**有没有脸、在哪** | 这张脸**是谁** |
| 输出 | 人脸框（+关键点） | 一个人的 ID / 名字 |
| 类比 | 门卫看见"有人来了" | 门卫认出"是张三" |
| 典型算法 | Haar、MTCNN、RetinaFace、YuNet | FaceNet、ArcFace、InsightFace |

> **人脸识别是建立在人脸检测之上的**：先检测出脸（在哪），再识别（是谁）。很多新手把两者混为一谈，这是人脸领域最大的认知误区。

---

## 二、人脸检测：从 Haar 到深度模型

| 方法 | 年份 | 特点 |
|------|------|------|
| Haar 级联 | 2001 | 快、极轻量，但对角度/光线/遮挡脆弱（前面笔记讲过） |
| **MTCNN** | 2016 | 三段级联 CNN：先粗后细，同时输出人脸框 + **5 个关键点**（两眼、鼻、嘴角） |
| RetinaFace | 2019 | 更强，额外做关键点+密集人脸检测，遮挡/小脸更好 |
| **YuNet** | 2021 | OpenCV 内置 DNN 人脸检测，一行加载、效果好、可离线（代码里就用它） |

**MTCNN 的三段式思路**（P-Net → R-Net → O-Net）：

```
① P-Net: 在全图上快速粗筛大量"可能是脸"的小区域
     ↓ 用 NMS 粗去重（回顾 detection-concepts 的 NMS！）
② R-Net: 对候选区用稍复杂的网络精筛，去重
     ↓ 再用 NMS
③ O-Net: 对剩下的精细分类 + 回归 5 个关键点
```

> **MTCNN 巧妙之处 = 级联思想（Haar 那边见过）+ 深度学习 + NMS 贯穿始终。** 你学过的每个组件都在这里串起来了。

**关键点（landmark）为什么重要**：5 个关键点（左眼、右眼、鼻尖、左嘴角、右嘴角）用来做**人脸对齐**——把歪着的脸"转正"，这是下一步识别的关键预处理。

## 三、人脸识别流水线：四步

```
① 检测       ② 对齐       ③ 特征提取       ④ 比对
找出脸在哪 → 用关键点把脸转正 → 提取"人脸向量" → 算相似度，判断是谁
Haar/MTCNN   (仿射变换)     FaceNet/ArcFace   余弦相似度+阈值
```

### 第③步：把一张脸变成一个"向量"（Embedding）

这是核心思想：**把"一个人的脸"映射成高维空间里的一个点（向量）**。

- 同一个人的不同照片 → 向量**靠得近**
- 不同人的脸 → 向量**离得远**

```
              A 的两张照片
               · ·
              /   \
  猫脸 ·     /     \  · B 的照片
  (不是人)   ·A向量·       ·
```

> **识别的本质 = 向量空间里的"距离"问题。** 训练的目标：让同类近、异类远。这跟分类器不一样——它不是直接说"你是谁"，而是给一个位置让你自己比。

### FaceNet（2015）：三元组损失（Triplet Loss）

训练时每次取 **3 张图**：一张**锚图 A**、一张**同一个人 P**、一张**不同人 N**。

```
想让： 距离(A, P) 小，距离(A, N) 大，且至少拉开一个间隔 m

损失 = max( 0, d(A,P)² − d(A,N)² + m )
        │            │          │
        │            │          └ 间隔(如0.2)，留出缓冲
        │            └ 不同人距离
        └ 同人距离
```

- 损失 = 0：已经满足"同人近、异人远"
- 损失 > 0：还差多少，就梯度下降优化多少（呼应你的梯度下降笔记）

### ArcFace（2019）：角度间隔，更强的思路

ArcFace 不做三元组，而是在分类的 **softmax 里加一个角度间隔 m**：

- 普通 softmax：按类别的余弦相似度大小分类
- ArcFace：给"正确类别"的角度加上一个间隔，让模型被迫把同类挤得更紧、类间拉得更开

**效果**：判别力更强，成了工业界主流（人脸支付、门禁都用它）。

## 四、第④步比对：余弦相似度

两个向量 $A, B$ 的相似度：

$$\cos\theta = \frac{A \cdot B}{\|A\| \, \|B\|}$$

| 余弦相似度 | 含义 |
|-----------|------|
| 接近 1 | 同一个人（方向一致） |
| 接近 0 | 无关 |
| 负值 | 相反方向 |

**应用**：设定一个阈值（如 0.6），相似度高于阈值 → 判定为同一个人。**阈值是工程调参的关键**：调高减少误认（安全场景），调低减少漏认（便利场景）。

## 五、实际应用注意（面试/工程常问）

| 问题 | 答案 |
|------|------|
| 侧脸/戴口罩识别不了？ | 需要多角度训练 + 关键点对齐，口罩会挡住特征，专用模型 |
| 双胞胎怎么区分？ | 相似度极高，需要更强特征（ArcFace）或更多信息 |
| 照片能骗过吗？ | 会。需要**活体检测**（眨眼、摇头、3D 深度）防照片/视频攻击 |
| 数据库里人很多怎么办？ | 建**向量索引**（FAISS 等），不用逐个比，检索近似向量 |
| 隐私合规 | 人脸是敏感生物特征，采集/存储需授权（GDPR/个保法） |

> **工程上记住：人脸识别方案 = 检测(MTCNN/YuNet) + 对齐 + 特征模型(ArcFace) + 向量库(FAISS) + 活体检测。**

## 六、本篇一句话总结

| 概念 | 一句话 |
|------|--------|
| 检测 vs 识别 | 检测=在哪，识别=是谁，识别建立在检测之上 |
| 人脸检测 | Haar/MTCNN/RetinaFace/YuNet，关键点用于对齐 |
| Embedding | 把脸映射成向量，同类近、异类远 |
| FaceNet | 三元组损失拉开"同人-异人"距离 |
| ArcFace | softmax 加角度间隔，判别力更强 |
| 比对 | 余弦相似度 + 阈值判断是否同一个人 |
| 活体检测 | 防照片/视频攻击，支付/门禁必须 |
