## 一、直观理解

上一篇的 CNN 解决的是**图像分类**：整张图里"有没有猫"。但你问的是**"猫在哪"**——要框出来、还要知道框里是不是猫。这就是**目标检测**。

四个概念一字排开，先分清任务级别：

| 任务 | 输出 | 举个例 |
|------|------|--------|
| 图像分类 Classification | 整张图是什么类 | "这张图是猫" |
| 图像定位 Localization | 一个物体 + 框 | "这是猫，在左上角" |
| **目标检测 Detection** | **多个物体 + 各自的框和类** | "两只猫、一只狗，各给一个框" |
| 图像分割 Segmentation | 逐像素标类别 | "把猫的每个像素涂出来" |

> **目标检测 = 分类 + 定位，而且是对图里的每个物体都做一次。**

---

## 二、边界框（Bounding Box）

检测输出的"框"通常有两种表示方式：

```
方式1：左上角 + 宽高        方式2：中心点 + 宽高
(x, y, w, h)                (cx, cy, w, h)
框 = 从(x,y)向右w、向下h    框 = 中心在(cx,cy)、宽w高h
```

**手算示例**：一张 100×100 的图里，猫的框是"从左上角 (30, 20) 开始，宽 40、高 50"。

- 表示方式 1：`(30, 20, 40, 50)`
- 表示方式 2：中心 = `(30+40/2, 20+50/2) = (50, 45)` → `(50, 45, 40, 50)`

> 两种表示在代码里经常互换，`07_license_plate.py` 里就能看到。检测模型喜欢用中心点表示，因为好回归。

---

## 三、IoU（交并比）：两个框有多像

检测时模型会预测一堆框，怎么判断"这个框猜得准不准"？用 **IoU**：

$$\text{IoU} = \frac{\text{交集面积 (Intersection)}}{\text{并集面积 (Union)}}$$

```
两个框的重叠：
┌──────┐
│  A   │
│   ┌──┴──────┐
│   │  重叠   │  B
└───┴──┐      │
       └──────┘

IoU = 重叠面积 ÷ (A面积 + B面积 − 重叠面积)
```

**手算一个完整例子**：

```
框 A: (x=2, y=2, w=4, h=4)  → 占 x∈[2,6], y∈[2,6]
框 B: (x=4, y=4, w=4, h=4)  → 占 x∈[4,8], y∈[4,8]

交集: x∈[4,6] 宽2，y∈[4,6] 高2 → 面积 = 2×2 = 4
A面积 = 4×4 = 16
B面积 = 4×4 = 16
并集面积 = 16 + 16 − 4 = 28

IoU = 4 / 28 ≈ 0.143
```

**IoU 的常见用途**：

| 用途 | 规则 |
|------|------|
| 判断"框对没对" | 预测框 vs 真实框 IoU > 0.5 算命中（COCO 更常用 0.5:0.95 取平均） |
| NMS 去重 | 两个框 IoU 太高 → 说明在框同一个物体，去掉低分那个 |

> **IoU = 衡量"框得有多准"的一把尺子，范围 [0, 1]，越接近 1 越准。**

## 四、NMS（非极大值抑制）：一张图只留一个框

目标检测会生成**大量候选框**，同一个物体周围可能围着几十个框，得分有高有低。**NMS 的任务：把重复框去掉，每个物体只留得分最高的那个框。**

**算法步骤**：

```
输入：一堆候选框，每个带一个"置信度分数"(这个框里是物体的把握)
1. 按分数从高到低排序
2. 取分数最高的框，直接保留
3. 把所有和它 IoU > 阈值(通常0.5) 的框全部删掉（它们在框同一个物体）
4. 在剩下的框里重复 2~3，直到没有框剩下
```

**手算例子**（同一只猫的 3 个候选框，NMS 阈值 0.5）：

```
框1: 分数 0.95
框2: 分数 0.80, 与框1 IoU = 0.82
框3: 分数 0.70, 与框1 IoU = 0.15, 与框2 IoU = 0.20

第1轮: 保留框1(最高分)。框2 与框1 IoU=0.82 > 0.5 → 删掉。框3 与框1 IoU=0.15 ≤ 0.5 → 保留。
第2轮: 剩下框3，保留。

结果: 保留 [框1(0.95), 框3(0.70)]
解读: 框1和框2都在框同一个物体（重叠太大），留高分框1；框3在框另一只猫，单独留下。
```

> **NMS = "同一个物体只留一个最高分框"的清洗步骤。** 阈值越低删得越狠（可能漏检），越高保留越多（可能重复框）。

## 五、置信度与类别概率

检测模型的每个预测框输出两部分：

```
每个框 = 一个位置 + 两组分数
  ├─ objectness 置信度：这里有没有物体？（0~1）
  └─ 各类别概率：若有物体，属于哪一类？（如 猫 0.9 / 狗 0.05 / 鸟 0.05）

最终分数 = 置信度 × 类别概率
```

比如 YOLO 里，一个框如果输出 `置信度 0.8` 且 `猫的概率 0.9`，那么"这是猫"的最终得分就是 0.8×0.9 = 0.72。**得分低于阈值的框直接丢弃。**

> **置信度负责"有没有"，类别概率负责"是什么"，两者相乘才是最终信心。**

## 六、评估指标：怎么量化"检测得好不好"

### 先分清 TP / FP / FN（对照学过的东西理解）

| 缩写 | 含义 | 例（目标是检测猫） |
|------|------|-------------------|
| TP 真阳性 | 框对了，真的有猫 | 在猫的位置给出了框 |
| FP 假阳性 | 框错了，那里没猫 | 把狗框成了猫 / 空框给了猫 |
| FN 假阴性 | 该框没框 | 漏掉了图里的猫 |

### Precision（精确率）与 Recall（召回率）

$$\text{Precision} = \frac{TP}{TP + FP} \qquad \text{Recall} = \frac{TP}{TP + FN}$$

| 指标 | 回答的问题 | 高意味着 |
|------|-----------|---------|
| Precision | 我框出来的东西里，多少是真猫？ | 很少误报 |
| Recall | 图里真正的猫，我框出了多少？ | 很少漏检 |

> 两者常是矛盾的：框得保守（只框最有把握的）→ Precision 高、Recall 低；框得激进（什么都框）→ Recall 高、Precision 低。**调"分数阈值"就是在两者之间找平衡点。**

### mAP（mean Average Precision）

- 把不同阈值下的 Precision-Recall 画成曲线，**曲线下的面积**叫 AP（一个类别的平均精度）。
- 所有类别求平均 → **mAP**，是目标检测最常用的总指标。

> **mAP = 检测算法的"综合得分"，衡量它在所有物体类别上框得有多好。**

## 七、检测的两种范式（下一篇的预告）

做检测有两条技术路线，下一篇笔记详细展开：

```
路线A：两阶段 (Two-stage)          路线B：单阶段 (One-stage)
 ① 先生成候选区域(可能有物体)       ① 一次性直接预测
 ② 再对每个候选区做分类+精修          "框在哪 + 是什么"
 准，但慢                         快，用于实时
 (R-CNN / Faster R-CNN)           (YOLO / SSD)
```

> 用人话：两阶段 = "先圈出几个候选区，再一个个细看"；单阶段 = "扫一眼全图直接给结果"。YOLO 能实时跑（自动驾驶、摄像头），靠的就是单阶段。

---

## 八、本篇一句话总结

| 概念 | 一句话 |
|------|--------|
| 检测 = 分类+定位 | 每个物体给一个框 + 一个类别 |
| 边界框 | (x,y,w,h) 或 (cx,cy,w,h) |
| IoU | 交集÷并集，衡量框得准不准 |
| NMS | 同一物体只留最高分框，删重复框 |
| 置信度×类别概率 | 每个框的最终得分 |
| Precision/Recall/mAP | 误报、漏检、综合得分的量化 |
| 两阶段 vs 单阶段 | 先圈候选再细看 vs 直接输出 |
