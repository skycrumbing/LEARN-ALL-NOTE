# MySQL

> 学习目标：从存储、排序、事务、一致性到查询优化，系统掌握 MySQL（InnoDB）的底层机制与实战技巧。

## 学习内容

- [x] 数据存储：B+ 树、数据页（Page）、聚簇/非聚簇索引、Buffer Pool
- [x] 排序：Filesort、归并排序、K 路归并、sort_buffer
- [x] 事务：ACID、四种隔离级别、MVCC、锁机制、undo/redo log
- [x] 一致性：Binlog、主从复制、主从延迟、CAP
- [x] 查询优化：EXPLAIN、索引优化、JOIN、慢查询、分页
- [x] 实战案例：设备激活死锁排查（短事务 + RC 隔离）
