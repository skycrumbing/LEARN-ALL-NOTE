# AI 学习计划

> 用 AI 辅助系统学习四个学科：计算机科学、数学、网络、物理。

## 项目目的

本项目是一个**AI 辅助学习仓库**，旨在通过 AI 工具（如 Claude）帮助我系统性地学习四个核心学科：

| 目录 | 学科 | 学习方向 |
|------|------|----------|
| `computer/` | 计算机科学 | 数据结构、算法、操作系统、编程语言、数据库等 |
| `math/` | 数学 | 高等数学、线性代数、概率统计、离散数学等 |
| `network/` | 网络 | 计算机网络、TCP/IP、HTTP、网络安全等 |
| `physics/` | 物理 | 经典力学、电磁学、热力学、量子物理等 |

每个学科目录下，通过结构化的笔记、习题、总结和项目，配合 AI 进行讲解、答疑、出题和批改，形成完整的学习闭环。

### 为什么用 AI 学习？

- **按需讲解**：遇到不懂的概念，AI 可以用不同角度反复解释，直到理解为止。
- **即时出题**：学完一个知识点，AI 可以立刻生成习题并批改答案。
- **知识串联**：AI 能看到学科之间的联系，帮助建立跨学科的知识网络。
- **进度自定**：完全按照自己的节奏推进，不受课程表的限制。

## 目录结构规范

### 顶层结构

```
AI/
├── README.md          # 本文件，项目说明
├── computer/          # 计算机科学
├── math/              # 数学
├── network/           # 网络
└── physics/           # 物理
```

### 学科目录结构

每个学科内部建议按**主题（topic）**组织，而不是按时间或文件类型堆砌。推荐结构：

```
math/
├── README.md              # 学科学习计划、当前进度、参考资源
├── linear-algebra/        # 主题：线性代数
│   ├── README.md          # 该主题的学习大纲、已完成内容
│   ├── vectors.md         # 笔记：向量
│   ├── matrices.md        # 笔记：矩阵
│   ├── exercises.md       # 习题（AI 生成 + 自己作答）
│   └── summary.md         # 阶段性总结 / 思维导图
├── probability/           # 主题：概率论
│   ├── README.md
│   ├── basics.md
│   ├── distributions.md
│   └── exercises.md
└── calculus/              # 主题：微积分
    ├── README.md
    ├── limits.md
    ├── derivatives.md
    └── integrals.md
```

### 文件命名规范

| 规则 | 示例 | 说明 |
|------|------|------|
| 全小写 + 连字符 | `data-structures.md` | 目录和文件名使用英文小写，单词间用 `-` 分隔 |
| README 大写 | `README.md` | 每个目录下的说明文件必须叫 `README.md` |
| 不混用中英文 | 目录名只用英文 | 内容是中文还是英文随意，但路径名统一用英文 |

### 文件类型说明

| 文件 | 用途 |
|------|------|
| `README.md` | 每个目录的入口，说明该目录包含什么、学习进度如何 |
| `*.md` 笔记文件 | 学习笔记，可按子主题拆分为多个文件 |
| `exercises.md` | 习题集，推荐用表格记录题目、答案和批改结果 |
| `summary.md` | 阶段性总结，把零散知识整理成体系 |

## 如何与 AI 协作学习

### 推荐学习流程

```
1. 选定主题 → 2. 创建笔记文件 → 3. 让 AI 讲解 → 4. 记笔记
    ↑                                        ↓
    7. 复习总结 ← 6. AI 批改 ← 5. AI 出题练习
```

### 常用提问示例

**讲解概念：**
> 在 `math/linear-algebra/vectors.md` 中，帮我讲解向量点积的几何意义，用直观的例子说明，不要只给公式。

**出题练习：**
> 在 `computer/data-structures/` 目录下，我刚学完二叉搜索树，请出 5 道由浅入深的练习题，标记难度。

**批改答案：**
> 我在 `network/exercises.md` 中写了几道 TCP 三次握手的回答，请帮我批改，指出错误和遗漏。

**生成总结：**
> 根据 `physics/electromagnetism/` 目录下的所有笔记，帮我写一份 summary.md，画出知识图谱。

### 关键原则

1. **先自己写，再让 AI 批改** — 不要直接让 AI 给答案，先尝试自己解答，再让 AI 纠正。
2. **笔记要自己整理** — AI 可以辅助讲解，但笔记的文字必须是你自己理解后写下的，这样才能形成长期记忆。
3. **定期回顾** — 利用 `summary.md` 定期做阶段性总结，让 AI 帮忙检查遗漏。
4. **跨学科连接** — 学到一个概念时，问问 AI 它在其他学科中的对应物（例如：傅里叶变换在数学 → 信号处理 → 量子物理中的不同角色）。

## 快速开始

1. 在某个学科目录下创建主题文件夹：
   ```bash
   mkdir -p computer/data-structures
   ```

2. 创建笔记文件并开始学习：
   ```bash
   touch computer/data-structures/README.md
   ```

3. 在 Claude 中提问，开始你的 AI 学习之旅。
